# R09 一致性检查

草稿，待注册人员确认。所属Agent：registration。仅供开发环境测试，不可作为生产发布版本。

## 适用范围

核对已导入资料中的文字写法并列出有据可查的候选差异。本草稿只覆盖对比器械 K 号写法核对，不能仅凭出现次数认定哪个编号真实正确或对比器械适用。处理差异的建议属于过程判断，按当前权限模式进行，最后交人审核。事实缺失或超出范围的事项列入不确定事项，不编造法规结论。

## 工作方法

阅读后端随对话提供的项目 AGENTS.md 与本技能，用 plan_update 列出取证、写稿保存、检查送审三个步骤。每完成一步，用一句话汇报已经读到什么、下一步是什么。新核查直接查看资料库，旧核查稿只在用户要求修改或比较该稿时读取。搜索摘要、工作区草稿和模型记忆不能充当原文证据。依据 AGENTS.md 的系统提示词工作方法及 v6 第 1.3 节。

doc_search 是大小写不敏感的原样子串检索。英文申报包优先查看 510(k) 摘要中的对比器械字段，检索 510(k) number 或 predicate device，首次取少量结果。选出相关的两三个位置，可在同一轮发起这些 doc_read 调用。根据返回的资料名、UUID、版本、页码和 snippetOffset 读取。不从全文广搜单字 K 或遍历全部命中。证据不足时，用更具体短语、摘要名称或已经实际读到的编号补查。依据 FDA《Content of a 510(k)》的对比器械识别部分，以及 SY-QP-15 A3 第 5.3 节和《设计开发输出清单》的资料定位字段。

doc_read 的 id 必须来自检索结果的 documentId，不能把资料编号当作UUID。优先将命中项的 snippetOffset 作为 offset，从命中附近读取默认1800个UTF-16字符；这与检索结果的分页 offset 不同。仅在引语或判断所需相邻上下文不完整时追加小片段，必要时调整 offset/limit 重读覆盖完整引语的一段，不拼接缺口或改写原文。不要自动沿 nextOffset 读完整页，也不要重复读已经覆盖的整页。记录前后两处原始写法及它们的来源，不从搜索摘要直接写结论。依据工具目录的 doc_read 说明、SY-QP-15 A3 第 5.3 节和本项目实际文件版本。

实际读到两处不同写法、各有完整可核验引语及足够相邻上下文后，就准备候选差异报告并进入自查和审核；仅为解除具体不确定性再补查。报告写明本次读取范围，不声称已穷尽整包；如果仍无法判断哪个编号正确，保留两种原文并列为待确认，不用更多重复检索代替人的确认。

将不同写法分别记录为带资料编号、版本、页码和逐字摘录的陈述。Word 页码是抽取单元，不冒称纸面页码；OCR 低置信内容和原始 PDF 占位页须明确说明限制。两条证据可以来自同一页的不同完整引语；仅改变空白重复同一引语不增加证据数。

有依据的过程判断写入 decisions。如果现有证据只证明写法不同，就保留差异，把正确编号列为待确认。只有缺少影响继续核查的事实时才用 ask_user。业务工具要求批准时，等 pending_approval 对应的浏览器决定。被拒绝后按原因调整。依据需求 V1.0 的最终结果审核与权限模式规则，以及 FDA 的对比器械识别指引。

用 ws_write 在工作副本新建简短核查报告，写清两处原文和定位、差异及待确认事项。新文件可省略 expectedSha256。用该工具回执的 draft.version 作为 workspace_save 的 expectedDraftVersion，保存成最新工作区版本。取保存回执的 workspaceVersion 组成最少充分的结构化提交。用 check_run 自查后，把已检查的结构化结果交 submit_for_review。每条引语须完整出现在本对话的 doc_read 回执中。程序重跑 V1/V3，并核验至少两条不同证据。依据 AGENTS.md 的工作区版本规则、工具目录和需求第 3.3 节的人工审核。

## 交付与审核

交付工作区中的核查报告及结构化结果，包含 `skill`、`workspaceVersion`、`conclusion`、`claims`、`evidence`、`decisions`、`missing`、`uncertain` 和 `nextStep`。每项过程判断列明事项、选择、备选、理由、出处和风险，判断中的原文同样须经过 `doc_read` 和 V1 检查。没有过程判断时传 `decisions: []`。K 号使用字符串，单位字段传 `null`。当前检查报告列出 V1 与 V3 的结果及 V2/V4/V5/V6/V7/V8 的未执行状态。

提交后等待浏览器审核卡的决定；对话中的“已批准”无效。通过只冻结本报告版本，不代表正确 K 号已获确认，也不代表已向监管机构提交。
