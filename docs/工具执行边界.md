# 工具执行边界（PR-08）

工具只能来自静态登记的已发布版本，目录冻结后不能被调用方改写。工具说明分别记录用途、适用时机、不适用情形、参数和示例；模型拿到的是按当前权限与模式过滤的目录。

每次调用都重新读取运行、会话、用户、角色、项目和目标。运行不能通过空项目/目标绕过其会话归属；目标方向变化、运行停止、会话归档或用户停用都拒绝继续。工具允许的角色与对象范围必须来自同一组绑定，回调也只能看到这组授权，不能拼接另一个角色的全局范围。

| 级别 | 处理 |
|---|---|
| read | 按权限读取，输出有界并标资料级别 |
| reversible_write | 仅执行模式、活动目标、具备完整撤销契约才执行 |
| external | 只调用提案工厂；未接入时明确返回“尚未建立真实提案”，不调用执行回调 |
| irreversible | 始终拒绝 |

审批与安全配置管理不能以Agent身份执行；没有公开工具执行HTTP入口。真实浏览器身份仍只由Cookie、CSRF及来源校验获得，不能把Agent权限主体伪造成浏览器身份。

调用先锁定幂等标识，再按用户→工作区→目标→对话→运行的顺序核对并锁定上下文。角色行也锁定，撤权与已授权事务按先后串行。相同运行/调用编号仅生效一次；参数或工具版本变化拒绝复用编号。

可撤销写入先捕获原值和版本，在同一SQL事务内保存撤销记录、执行业务、验证新版本并保存会话回执。写入必须推进版本；失败整体回滚。原值模式只规范化一次，保存解析后的JSON结果并检查大小；撤销不重复运行非幂等变换。快照传入回调前冻结，防止回调改写目标或期望版本。撤销检查当前版本，之后有人修改过则拒绝；只允许同一用户、会话、项目和目标，重复撤销不重复生效。

tool_invocation仅存元数据和参数哈希；返回正文属于私有conversation_tool_result，不能进入run_event/审计，通用只读角色没有读取权。动态资料工具必须提供当前级别刷新方法，重放前重验权限/有效性/级别，不能从旧缓存降低级别。

此PR使用真实数据库事务剧本验证框架，不等于Agent内核已实现。完整Agent测试及技能评测在PR-20/21接入时进行。实际工作区写工具必须改为复用执行器tx后才能登记，不能直接调用另开事务的旧封装。
