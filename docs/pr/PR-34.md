# PR-34 M02 美国公开资料核查与定时唤醒

美国维护目标负责人在项目左侧「工作目标」启用或停用定时核查。后台按项目法域计算月份及年度注册窗口。负责人离线时在新维护对话使用固定版规则包核对公开回执、确认事实及内部归档，按照现有权限设置年度站内提醒并提交审核。停用停止后续扫描，已产生的对话保留。规则包和技能均为开发草稿，待注册人员确认。[决定 D-066](../决定记录.md#d-066-m02-定时核查与公开回执)

`official_lookup` 补充企业注册及列名按 K 号和产品限定、完整法定名称登记查询、以及产品代码结合 K 号或商品名的 openFDA UDI 查询。只在已授权的 FDA 托管地址查询。核查将官方数据、公司归档和历史观察分开，保留来源、查询时间与失败原因。开发验收使用公开 L08 线索和独立合成档案，禁止真实发信。[FDA 企业注册与列名字段](https://open.fda.gov/apis/device/registrationlisting/understanding-the-api-results/) · [FDA UDI 字段](https://open.fda.gov/fields/deviceudi_reference.pdf) · [E12、E13 用例](../../evals/m02/README.md)

## 验收

- `pnpm test:int apps/backend/src/goals/m02-schedule.int.test.ts` 检查浏览器 Cookie、CSRF、负责人、版本重复、法域日界线、窗口前唤醒、规则包固定、项目关闭与数据级别。
- `pnpm test:m02` 使用真实浏览器启用定时核查并退出。由后台生成新对话，核对 FDA 的三个查询和档案，验证站内提醒和待审核卡，然后返回浏览器查看。1440×900 截图与原始回执留在隔离验收环境。
- `pnpm docs:html` 更新离线文档。原有通用检查及标准 R09、M02、Cursor 和 OpenRouter 真实走查仍运行。

## 没做什么

- 正式环境技能和规则包等注册人员审阅发布。数据源无结果时由人工复核适用性。付款、签名、监管门户操作和对外联系由人处理。
- 当前确认规则为 V1 与 V3，V2 可用独立编号核验工具，V6 取具有计算回执的结构化期限。V4 全面的资料语义对照未实现。单个目标沿用一项站内提醒。
