# PR-41 业务语义层与只读台账查询

注册和维护 Agent 均使用 `cert_query`。工具按 [K11 草稿](../数据与评测方案/K11_概念目录_1.0.0.md) 执行五个固定模板。每条回执包含口径、查询时刻、范围、目录版本、数据缺口和截断状态。记录来源包括表、记录编号和版本。市场授权的可售判断同时列明支持它的证照版本。

默认只查当前项目。部门范围使用现有注册人员的读取权限。台账数据在受控流程写入核验范围后才能确认空结果，已有但覆盖不全的记录可以作为部分答案。待审核卡以现有待处理系统为准。日期按项目法域计算。只读查询通过现有 PostgreSQL 无登录角色执行，语句时限为 1.5 秒，单次返回上限为 100 行。

在项目的只读对话中提问，打开「运行详情」，可在相应工具步骤下核对查询类型、可回答性、范围、目录版本、查询时刻、计算口径及数据缺口。计算口径来自回执对应版本的目录。刷新后可从对话记录再次打开。界面沿用设计稿 11 的时间线，在台账查询步骤下增加回执字段。

## 验收

- 证照查询验证法域日期、到期日首尾边界、长期有效和缺字段。
- 型号状态与可售名单验证有效证照、市场和覆盖范围。逾期节点验证完成日期、今天的边界和截断。
- 待审核查询使用实际提示卡测试部门成员读取与截断，未经审阅的生产目录返回无法回答。
- 只读角色的写入及账号读取应被拒绝。真实工具循环的剧本回归核对执行事件，详细台账行保留在受保护工具结果，事件只留结构化回执。
- Chromium 使用合成台账和剧本模型逐项验证「完整」「部分」「无法回答」，刷新后再次核对回执。回执区域只显示经会话授权的回执字段。浏览器真实模型走查仍按正式合并条件执行。[1440×900 实测截图](../evidence/pr41-11-cert-query-receipts.png)
