# PR-47 K05 文档模板草稿和逐段出处

## 当前切片

- 按 v7 K05 先提供一份基于公开 FDA 参考的通用 510(k) Cover Letter 草稿。模板在 `knowledge/k05/us-510k-cover-letter.yaml`，状态为草稿，待注册人员确认。
- 草稿按申请人、器械和申报缘由组织。正文保留待核位置。签署与日期由提交人审阅后填写。eSTAR 的 Cover Letter 部分作为草稿用途参考。[FDA 附件结构](https://www.fda.gov/media/152429/download) · [FDA Cover Letter 建议](https://www.fda.gov/medical-devices/premarket-notification-510k/content-510k) · [FDA 格式提示](https://www.fda.gov/medical-devices/premarket-notification-510k/510k-format-tips)
- 纯渲染器输出 Markdown 和逐段来源表。填入事实须逐字包含于指定资料版本和页面的引文中。校验失败时中止渲染。来源表记录规范参考、引用、待核字段和草稿哈希。合成样稿也可通过既有隔离沙箱编排成 Word。

## 开发验收

- `pnpm exec vitest run apps/backend/src/knowledge/draft-template.test.ts` 覆盖合成 Cover Letter、逐段出处、缺项、错误引用和未签署占位。
- `pnpm test:k05` 在本机 `.local/` 写入合成草稿和 JSON 来源表，每次建立新的目录，供开发走查。
- 独立验收机型检、lint、2 项专项单测及合成样稿生成通过。样稿和来源表在本机 `.local/test-vm/pr47-k05-sample/`。
- `pnpm dev:sandbox:up` 后运行 `pnpm test:k05:word` 可生成合成 Word 草稿。实测样稿在本机 `.local/test-vm/pr47-k05-word-final/`，来源表与 Word 文件哈希一致。已核对沙箱渲染的单页版面。
- 真实模型及最新版提交的正式合并流程继续按独立虚拟机约定执行。

- 提交审核时的全套 V1–V8 及文件命名联动留待继续实现。保留现行结果审核与原文检查的通用门禁。
