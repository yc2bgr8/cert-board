PR-U5 Orca 对话输入区与消息流

Lan 看过 .local/orca-chat-prototype 中的可点击原型后，确认用 Orca 聊天组件作底稿，优先替换输入区和消息流。这一轮在正式网页复用现有对话、浏览器请求和事件流。

  • 输入框按多行内容增高。工具条使用紧凑的资料、权限、停止和发送按钮。运行时仍可以插话，断流时发起人仍可停止。
  • 点击资料按钮或在消息末尾输入独立的 @，可从浮层筛选已加载的项目资料。已选资料以可移除的标签显示，切换对话后从原草稿还原，提交时仍按既有引用格式传给后端。已发气泡显示资料号和版本。
  • 消息气泡、Agent 名称和正文、可展开工具步骤使用原型的排版。工具步骤状态有文字，审核与外发提案沿用既有业务内容和操作。
  • 组件与样式参考 Orca 提交 bc8085021b0a7e046925901a2f857361dd929686，源码保留出处，MIT 声明见 third_party/orca/LICENSE。应用已有的字号与色板用于具体令牌。本 PR 没有新增运行时依赖。

验收

在干净 Linux 虚拟机运行通用检查。浏览器剧本验证输入框增高、@ 和筛选、标签显示、请求保留资料编号、发送后清理引用、运行中的权限切换、插话、停止、批准和审核。覆盖设计稿 04 的对话流程与 11 的停止流程，保留 1440×900 浏览器截图。另按 v6 做真实模型走查。

  • 设计稿 04：输入和资料选择集中在同一张卡片，资料版本在已发气泡可见，工具步骤有独立的折叠行与状态。批准请求仍在输入区上方。输入区 · 消息与工具过程
  • 设计稿 11：停止用工具栏里的方块按钮，停止汇报与运行详情保留原状态和操作顺序。停止后的运行详情
