PR-38 安全检查与端到端验收

pnpm test:network 在隔离部署中核对业务代理和沙箱代理各自的白名单。探针开始后，逐行检查两路日志的输出与错误流。可能发起了连接的记录必须是白名单主机的 HTTPS CONNECT。非白名单主机只有明确的拒绝记录可以出现。验收还要求预期的证书校验、连接成功和拒绝记录齐备。报告只显示统计，原始日志留在独立验收机。

项目首页的「工作目标」提供负责人接管与交还入口，记录接管说明或处理结果。返回项目首页时重新读取目标，保存使用打开操作时的版本。遇到版本冲突时禁用旧提交，保留说明并刷新目标状态。后端核对目标负责人，在预占请求交给传输器前锁内复核目标及方向版本。

pnpm test:e2e 使用剧本 Agent 登记等待。Chromium 点击实际接管和交还入口，核对缺失 CSRF、过期版本以及接管中无唤醒。交还后只创建一个新对话，Agent 收到处理记录，浏览器显示续跑回复。

独立虚拟机验收

使用无模型凭据的独立 Linux 虚拟机和开发账号。启动隔离服务后运行 pnpm test:network，再关闭本轮隔离服务。浏览器使用虚拟机上已安装的 Chromium。工作台只允许回环地址，探针沿用已登记的域名。代理检查包含未授权主机的成功与失败记录、错误端口、非 CONNECT、两路代理混用白名单和拒绝记录缺失的合成回归。
