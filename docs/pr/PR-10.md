## PR

PR-10 预算与精确计量

## 做了什么

- 每次模型调用先预占再结算，运行、目标、北京时间月度和整晚总额共同约束；未知计量保留预占并停止后续调用。
- 金额用整数nanoUSD，价格单位明确为美元/百万token，累计快照不重复累加。
- 未知价格不发请求，超预占实际费用仍如实记录后停止；预算阈值和拒绝留下不含正文的审计。
- `pnpm budget:status` 只输出金额、计数和停止状态，便于核对整晚累计费用。

## 没做什么

- 真实模型请求、最大输出与上游价格限制在PR-12网关接入，本PR不调用模型。
- Agent逐轮停止汇报在PR-20接入；目标完整状态机及负责人通知在PR-28及通知PR完成。
- 预算管理界面、调高额度入口和生产预算批准留后续；提高额度不会自动恢复运行。
