## PR

PR-09 提案、浏览器审批与本地测试队列

## 做了什么

- 新0005建立proposal、decision、outbound_message及目标外发暂停标记；来源运行/调用/项目/目标和收件人均绑定，正文、收件人快照与哈希不可改。
- propose_external通过已登记external工具和同一tx建提案，只有已登记有效local_test联系人，无直接发送回调。
- 审批只在路由闭包内验证真实Cookie/CSRF/Origin，重新锁会话/用户/角色；版本和内容绑定，重复请求不重复排队。
- 暂停保留未发，恢复取消旧队列并要求重新审批；执行前重查目标、批准版本、内容哈希和联系人版本/姓名/地址。未知结果reconcile不重放。
- 固定本地处理器只记录测试回执，生产拒绝，不调用任何外部对象；新增静态边界禁止工具/worker导入审批、浏览器会话和宿主机执行器。

## 没做什么

- 真实邮件、企业微信、监管门户无发送实现；没有新增出网地址。
- 附件、提案编辑重提界面、通知和常驻轮询未接入；本PR只完成文本本地测试安全流程。
- 本切片只处理active目标，其他等待态业务流转后续完善。专业审核卡与工作区冻结仍为PR-16。
- 完整Agent工具说明评测待PR-20/21；不把策略/事务测试称为模型行为验收。
