# PR-24 技能版本管理

## 操作

1. `pnpm skill:stage "skills/R01-注册立项演示/SKILL.md"` 登记合成演示草稿。版本正文登记后只可增加新版本。
2. 登录工作台，在「设置」打开「技能版本」。选择技能及版本，阅读正文、所需检查及证据数。在审核卡点「批准并发布」。
3. 选择正在生效的版本可点「停用当前版本」。选择此前已经人工发布的上一版可点「退回上一版」。历史版本和被停用版本的原文继续保留。

1440 × 900 合成浏览器验收截图见 [批准发布](../evidence/pr24/skill-review.png) 和 [退回上一版](../evidence/pr24/skill-rollback.png)。

## 验收口径

- 仅接受浏览器登录和 CSRF 验证。重复操作编号只执行一次，陈旧版本号或不一致的内容哈希会被拒绝。
- 发布、停用、回退均有操作者和前后哈希，版本正文与审核事件只追加。
- 注册与维护 Agent 分别显示本方生效技能。未生效、已停用、错版本或模式不符的技能无法新加载。
- `submit_for_review` 读取技能的当前版本并执行其中的检查和最少证据数。原有原文和结构检查仍是发布前必须配置的项。

## 本次边界

- 技能格式可登记建议的子任务、评测名称及预算初值。预算初值接入单技能额度、附件上传及评测结果参与发布门禁待后续。Agent 定义沿用开发草稿入口，生产运行仍待审阅版本接入。
- 本次仅使用合成演示草稿和剧本。未新增真实模型开销。
