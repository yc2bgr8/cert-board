# PR-U3 审核与证据

审核卡显示八部分，滚动正文时「通过」和「退回修改」留在右栏底部。证据页可以单份或双栏查看引用附近的原文，也可以展开整页解析文字。改动对比按文件展示两个已保存版本的逐行变化。

## 接口与参考

- 审核卡和提案决定沿用现有浏览器会话与版本检查。对话中的提案历史分页返回编号与状态。正文和联系人在单条提案中查阅。
- 证据布局参考 VisaFlow 的 `MaterialRecognitionDialog.tsx`。文件对比按 Craft `UnifiedDiffViewer.tsx` 的统一行布局适配已经分页的行数据。源码附出处，仓库内保留 Apache-2.0 LICENSE 和 NOTICE。
- 暂未实现的反馈、审批变体、原件与台账对比逐项记录在[待办](../待办.md)。

## 验收

- lint、类型检查、397 项单元和构建通过。提案列表首次读取期间收到的状态变化会在请求完成后补刷，补刷期间暂停分页。
- 41 项隔离库浏览器验收通过。L08 两处原文逐字核对、高亮可见、浏览器审核冻结、重复打开和重提差异均通过。提案拒绝后没有队列项，批准后产生一条 `local_test` 待处理记录。处理完的提案从待办移除，原对话仍可回看。浏览器真实外部请求、页面错误、内容安全策略违规和真实模型费用均为 0。
