PR-C4 审核卡增加过程判断

做了什么

  • 新结构化交付包含 decisions[]。每条过程判断含事项、选择、备选、理由、资料库引语和风险。未作过程判断的提交传空数组。
  • V1 检查判断引文是否出现在对应版本页。提交还要有本对话完整读取回执，浏览器查看和决定前复核来源有效性。
  • 后端提供八部分审核内容。高风险卡立即显示完整结果，部门成员可以查看并作决定。记录实际决定人，继续校验版本、来源和冻结条件。
  • 历史卡按原始结构校验哈希。读取时把过程判断展示为历史未记录。旧独立判断、历史审核结果及冻结快照继续保留。

没做什么

  • 八部分的正式浏览器界面与原文卡在 PR-27 接入。过程批准后执行原调用和续跑在 PR-21 接入。
  • 当前继续支持通过与退回。修改后通过、追问、转交和后续唤醒按执行方案继续实现。
