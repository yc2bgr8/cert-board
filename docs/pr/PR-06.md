## PR

PR-06 资料库、版本和T1开发种子

## 做了什么

- 新0002建立document/version/page，原文与版本只追加、不可覆盖，资料只能标作废不能删除；数据级别显式必填。
- 私有MinIO按实际内容SHA保存、去重、读取校验。原文件声明哈希与实际解析内容哈希分列，不声称原始PDF已导入。
- 幂等T1种子：59来源身份、664逐页记录，版本1是导入快照；新快照新版本，旧快照重放不切回旧版，同快照内容冲突拒绝。
- 授权仅读API、最小关键词检索（主路径前置PR-18）、有界摘要/正文和续读；作废和占位页排除，历史最高级别传播。
- 实际验证D035第1/5页两处不同K号摘录；Word抽取单元、低OCR置信度及eSTAR占位明确提示。

## 没做什么

- 单文件上传HTTP入口、原始文件存储导入、人工作废工具和界面、上传大小配置入口延后；不提前开放绕过工具的业务写入口。
- 原始PDF/Word、eSTAR XML正文、原页图像、解析服务和整包导入未实现；doc_search/doc_read模型工具在PR-21登记。
- 完整检索排名/索引及PR-18其余验收延后；当前逐页关键词匹配足以主路径。
- PG长中文substring异常根因未确定，保留回归并采用程序有界摘要，后续单独核查镜像补丁（D-010）。
