PR-23 子 Agent、插话与上下文压缩

  • 并行子任务使用同一 Pi 内核和父运行的模型网关账本。只开放显式登记的读取工具，草稿经回执交给父 Agent。引用须与本子任务成功读取的原文匹配。
  • 同字段陈述有分歧时暂停写入并向发起人提问。资料版本不一致时，相关子任务先重新读取最新可读版，再核对结论。未完成范围在结果中列出。
  • 对话过长时，经网关的压缩用途整理早期历史。最新的用户请求、近期轮次、已确认的项目说明与原有聊天记录都保留。插话沿用 Pi 轮次钩子，把新消息在当前工具结束后交给下一步。
