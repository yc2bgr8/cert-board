PR-11 执行事件、执行权与私有请求清理

做了什么

  • 扩展run的执行权和事件序号；run_event使用明确字段白名单和受控值，不记录资料正文、原始参数或凭据。
  • 事件只追加，引用绑定同一运行；租约以owner、generation和数据库到期时间识别。
  • 私有请求内容关联计量请求及其运行/用户，不授予通用只读角色；默认0天直接不存。
  • 提供pnpm requests:purge，按数据库时间批量清理到期内容，删除与只含元数据的审计同事务。非零保留只用于隔离库的合成测试。
  • 联动修复PR-10全局停止的锁顺序风险：真实费用与冻结先提交，其他运行在后置独立事务中停止；后置失败保留账目及冻结，不伪装结算失败。事件和租约也统一先锁对话再锁运行。

没做什么

  • Agent、模型网关与工具执行器的实际事件/执行权接入留PR-12/20/21；当前尚未宣称运行中的模型或工具已被lease保护。
  • 完整私有对话正文、实时SSE和运行界面留PR-20/25/26/27。
  • 真实请求正文的正期限保留暂不开放；默认0天的保守决定见D-015。
  • 尚未实现的管理操作与冻结审计随对应业务PR接入；清理常驻调度在worker接入时完成。
