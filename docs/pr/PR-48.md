# PR-48 S01 合规草稿事实追溯

## 本机候选范围

- 增加维护 Agent 的 S01 待审核草稿，由注册人员代销售提出问题。现行浏览器审核和外部交付的人工流程继续适用。
- 提供合成报告生成检验。字段取自在报告时点已生效的最新确认修订。按用途许可和原页的级别、报告主体与完整字段行核验，分别处理证照编号和申报编号。保密页只查看分类，待发放等占位留待核。报告只展示已核对的确认值。
- `pnpm test:s01` 生成固定合成输入的 Markdown 和 JSON 来源表。各事实行标出来源编号，记录主数据修订、资料位置与文件哈希。缺项理由留在草稿，输出样稿标为合成演练。

## 开发验收

- 定点覆盖确认修订、缺失或过期许可、原文与字段精确匹配、非日期文本、保密值、旧版本和不一致来稿。
- 独立虚拟机型检、lint 和 9 项专项通过。命令生成两条有效事实和四条待核，来源表与正文哈希一致。夹具的保密页无正文文件，合成命令仍通过。额外验证 `.local` 指向仓库外时拒绝生成。S01 在隔离 PostgreSQL 重复登记只保留一个待审核草稿，零发布记录。

## 没做什么

- 正式来源授权与附件包、批准后的实际工作区提交、公司模板及真实销售报告评审依赖 PR-43、PR-47 和可用的授权模型。当前演示入口只运行固定合成用例。
- 20 条 rp 评测和人工耗时对照在正式主数据与试用条件就绪后记录。
