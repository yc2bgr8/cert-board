# PR-23 子 Agent、插话与上下文压缩

- 并行子任务使用同一 Pi 内核和父运行的模型网关账本。只开放显式登记的读取工具，草稿经回执交给父 Agent。引用须与本子任务成功读取的原文匹配。
- 同字段陈述有分歧时暂停写入并向发起人提问。资料版本不一致时，相关子任务先重新读取最新可读版，再核对结论。未完成范围在结果中列出。
- 对话过长时，经网关的压缩用途整理早期历史。最新的用户请求、近期轮次、已确认的项目说明与原有聊天记录都保留。插话沿用 Pi 轮次钩子，把新消息在当前工具结束后交给下一步。

## 验收

| 场景 | 方法 |
|---|---|
| 多个子任务真的能并行，且共用账本 | 剧本模型在收到多个子任务请求后才放行，检查父运行和子任务的累计用量 |
| 子任务越权与父运行分歧保护 | 子任务尝试业务写入时拒绝，冲突同时生成的父 Agent 写入没有登记，原对话收到提问事件 |
| 引证版本变化 | 两个任务读同一资料不同版本后，分别重读最新版并核对逐字引文 |
| 预占步数 | 同父运行的并发请求不会越过步数上限 |
| 压缩与插话 | 剧本模型长历史、项目决定、真实原始消息计数与运行中插话回归 |

旧浏览器回归仍在查找资料导入的「尚未接入」占位。PR-19 已接入 ZIP 和目录导入。本次改为核对两个输入，且在选择资料前导入按钮不可用。原有证据入口及其余断言照常验收。

## 本次边界

- 早期摘要为当轮上下文，尚未保存独立摘要检查点。现可压缩最多 600 条历史。继续扩展及轮中压缩见[待办](../待办.md)。
- 子任务交回草稿，写入工作副本由父 Agent 通过登记工具完成。运行详情的子任务可视化随相关界面接入。
- 仅使用剧本及合成资料，真实模型测试费用为 0 美元。
