## PR

PR-C2 按附录A重做静态界面稿

## 做了什么

- 按变更单附录A重做白底、浅灰侧栏、对话居中及按需右栏，使用指定设计变量与系统字体。
- 演示注册Agent的请求批准、维护Agent的完全允许，以及待我处理中的批准请求和待审核结果。
- 过程判断进入八部分审核；计划、逐步进度和可展开工具过程留在对话中。角色选择、销售视图及高风险先写判断取消。
- 保留安全Markdown、本地资源策略，演示说明只在设置中显示。

## 没做什么

- 本PR仅静态交互，不接后端、真实模型、真实业务写入或消息发送；C3/C4/21/25/26/27继续实现正式行为。
- PDF原页和Word解析对比仍需后续解析服务；此处只展示虚构解析摘录和文本改动。
- 手机端按D16后续决定；本次主要验收1440×900和1280×800，并检查小于1024时侧栏收起。
- 静态稿每个项目只保留一条活动演示对话；已有运行、批准请求或待审结果时阻止新对话覆盖。真正多对话持久历史在PR-25/26实现。刷新页面会重置演示状态。

其他期望调整：主界面原型标记依A.8移到设置；证据文件名去掉“示例”字样，仍保持三类维护证据独立；拒绝后的结果按“保留差异/暂不选择正确编号”验证原有待确认语义。浏览器辅助脚本不再强求设置中出现“示例数据”四字，改为核对实际“虚构示例、仅本地交互、不调用模型后端、不向真实对象发送”说明，安全断言保持。

发现并先红后绿修复：只读或停止不再列出未执行的写入/提交；切回ask不能借旧finishing计时器绕过批准；无结果的原文页不能提前打开预设审核；新对话不能抹去待处理记录；搜索焦点及Tabs的controls/tabpanel关系修正。原生浏览器还发现Radix模态弹窗注入样式触发CSP，搜索/设置/反馈改为非模态对话，不修改CSP；三项style标签注入回归及真实浏览器复测通过。
