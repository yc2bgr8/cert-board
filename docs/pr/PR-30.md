# PR-30 官方数据客户端与标识符回查 V2

注册 Agent 和维护 Agent 可用 `official_lookup` 查询精确编号，经现有公开抓取服务访问 openFDA、AccessGUDID 和加拿大 MDALL。可写会话生成带查询时间、资料编号、版本和定位的公开存档。只读会话允许查询和读取已有存档。缓存按项目、截止日和页隔离。FDA 的限定查询通过决定日期过滤，MDALL 按许可证签发、器械及型号的加入和移除日期过滤。返回记录无可证实的历史版本时，工具提示查阅早期存档。[D-062](../决定记录.md#d-062-官方编号回查与历史证据)

`identifier_check` 执行 V2。它核对待查编号和比对编号各自所在的资料版本、页码、原文。精确匹配优先，相邻对调及相差一两个字符列为疑似笔误，修订交人确认。台账比对使用项目内已导入的台账原文。正式台账结构及全量导入留到 PR-43。

## 验收

- 从独立虚拟机录制并最小化八个公开数据响应，作为 `fixtures/official/` 的测试资料。夹具覆盖 K253845、K170825、FDA 分类和企业注册、AccessGUDID 器械记录、MDALL 公司 184937 的 21 张许可、器械和型号。
- `pnpm test:real --official` 通过隔离抓取服务复查两个真实 K 号的 LRK、21 CFR 872.5570、Class II。官方查询读取公开编号，不使用模型密钥。
- 独立 VM 专项 `pnpm test:official` 启停该客体的公开抓取服务，执行真实编号查询和真实浏览器专项。浏览器从 L08 原文读取 K170285，调用 `official_lookup` 保存 K170825 的公开证据，并通过 V2 同时核对两份原文。走查产物保存在本机，其回执与完整走查的稳定预览回执各自独立。
- 最终候选运行全部通用检查、上述专项和标准真实走查，PR 只记录脱敏结果和版本编号。
