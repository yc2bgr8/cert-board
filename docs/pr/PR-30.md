# PR-30 官方数据客户端与标识符回查 V2

注册 Agent 和维护 Agent 可用 `official_lookup` 查询精确编号，经现有公开抓取服务访问 openFDA、AccessGUDID 和加拿大 MDALL。可写会话生成带查询时间、资料编号、版本和定位的公开存档。只读会话允许查询和读取已有存档。缓存按项目、截止日和页隔离。FDA 的限定查询通过决定日期过滤，MDALL 按许可证签发、器械及型号的加入和移除日期过滤。返回记录无可证实的历史版本时，工具提示查阅早期存档。[D-062](../决定记录.md#d-062-官方编号回查与历史证据)

`identifier_check` 执行 V2。它核对待查编号和比对编号各自所在的资料版本、页码、原文。精确匹配优先，相邻对调及相差一两个字符列为疑似笔误，修订交人确认。台账比对使用另一份由可信导入流程标记为证照台账的项目资料。正式台账结构及全量导入留到 PR-43。

开发运维可将人工核对的台账解析快照通过 `pnpm ledger:import <本地 JSON 文件>` 重新导入。沿用资料导入字段 `projectId`、`sourceKey`、`name`、`sourcePath`、`sourceSnapshot`、`dataLevel` 和逐页 `pages`，`authorType` 填 `human`。用原台账 `sourceKey` 登记新版本时，已有版本保留，同一快照重复登记只生效一次。之后 V2 引用新版本。原始台账与解析文件保留在本机。

## 验收

- 从独立虚拟机录制并最小化八个公开数据响应，作为 `fixtures/official/` 的测试资料。夹具覆盖 K253845、K170825、FDA 分类和企业注册、AccessGUDID 器械记录、MDALL 公司 184937 的 21 张许可、器械和型号。
- `pnpm test:real --official` 通过隔离抓取服务复查两个真实 K 号的 LRK、21 CFR 872.5570、Class II。官方查询读取公开编号，不使用模型密钥。
- 独立 VM 专项 `pnpm test:official` 启停该客体的公开抓取服务，执行真实编号查询和真实浏览器专项。注册 Agent 读取 L08 的 D035 原文并回查 K170825，V2 识别对调，Agent 把两份依据送审，测试账号在浏览器批准。专项证据保存在本机。
- 两次开发诊断费用合计 0.813508 美元，另有一笔待核账。第一轮在模型调用阶段终止；第二轮完成官方抓取和 V2，运行因未提交审核停止。专项按 R09 正常送审路径复验。
- 初次正式验收的官方专项与标准走查通过，结算 3.5697276 美元。独立最终复审后补齐台账可信导入、编号后缀和限流等待边界，按新提交重新验收。
- 最终候选运行全部通用检查、上述专项和标准真实走查，PR 只记录脱敏结果和版本编号。
