# PR-43 M01 证照台账清洗预览

## 本机候选范围

- 按 K06 和注册部门现有清洗规则实现证照 CSV 的本地预览。首行核对全部模板列，多余字段列入报告。证照键用类型和编号，相同资料跳过，差异行供人工核对。支持常见年/月/日写法、Excel 1900 系统的日期序列、账号与显示名匹配以及有单位的费用。以原文件 SHA‑256 和实际起始行定位。
- 有「可售」「已列名」时检查至少有型号、市场和当前行的证照。多份证照同时声称同一型号和市场的授权时标出错误。企业级证照可留空型号。日期、人员和金额校验问题留在本机报告中。
- 增加 M01 待审核技能草稿。查阅、工作副本、期限程序和浏览器最终决定仍用既有入口。

## 开发验收

- `pnpm test:ledger-preview` 运行合成演示。也可用 `pnpm ledger:preview <证照CSV> <成员和现有证照快照JSON>` 生成当前用户目录中的本机预览。命令输出路径与整单数量，逐行报告保存在该私有目录。入口与现有导入命令沿用同一套 Node 和 tsx 启动方式。
- 专项测试覆盖日期、CSV 引号与带换行字段、证照主键、相同及不同数据重入、已有行冲突、人员匹配和型号市场冲突。上传同键冲突时保留基线值和两条拟议值。新增授权冲突不改变已有相同行的状态。
- 隔离虚拟机型检、lint 和 7 项专项通过。合成命令实测四类各 1 条，超限文件拒绝读取，预览目录和文件权限分别为 `0700`、`0600`。M01 草稿在隔离库登记两次只产生一个版本，发布记录为零。

## 没做什么

- 注册人员复核后的浏览器写入、多份台账联动、Excel 文件、原文件只读归档及正式证照到期任务尚待接入。此阶段预览保持原文件和业务现值。
- 正式台账查询与规则包发布依赖 PR-41、PR-42。真实公司证照、逾期目标、L08 品牌和代理人等未验证字段保留在评审范围，真实模型走查仍待可用渠道。
