## PR

PR-07 项目工作区与独立工作副本

## 做了什么

- 新0003：工作区、不可变版本与文件、对话私有工作副本及overlay；前置最小conversation表保证真实归属，组合外键阻止项目/用户/版本错配。
- 每文件SHA比较并交换、基础版本冲突；保留失败副本并返回有界变动路径。显式核对最新版本和草稿后重基，重叠改动需逐路径双方SHA确认，不提供force覆盖。
- 恢复生成新版本；决定记录只追加，写入/保存二次检查，恢复保留最新及未保存追加历史。最高资料级别传播且数据库禁止下降。
- 已发布版本禁止改动和追加文件，当前指针不能回退/清空；补snapshot同项目工作区版本外键。
- 路径NFC与越界防护、严格UTF8读取、完整字符分页、有界行对比及非文本哈希对比；公开API仅读。
- 幂等L08初始工作区5文件和资料引用清单；项目说明包含安全工作方法，不植入K号预期答案。

## 没做什么

- 审批冻结服务与HTTP入口留PR-16；没有给Agent提供冻结调用。
- Word解析对比、二进制内容预览留PR-27。文本差异有1百万码元/1万行/计算时间上限，长行与分页有限额，超限明确提示，不假装完整比较。
- 决定记录的并行分叉不自动重排或覆盖，需新建基于最新版本的对话再追加；原副本保留。
- 本PR内部写服务仍未暴露为模型工具，撤销/幂等与动作级别在PR-08/21接入；会话表不等于对话运行已实现。
- 项目说明模板当前仅静态约束测试，真实Agent回归在PR-20/21执行；没有把占位eval正常退出写成通过。
