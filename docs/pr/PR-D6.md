# PR-D6 外部模型入口

独立入口保存外部对话。发送前检查保密词、保密原文重合和本地内容策略，按月份预占单独预算。原样保存发出与返回，显示解码后的答复，按日期查看和下载外发记录。引用交给现有项目对话后按 Agent 的项目规则复核。

## 对照差异

- 14 使用已接入的工作区版本和文本文件选择器。准备状态下模型下拉和发送按钮锁定，外部对话仍可在本地新建及查看。
- 15 按北京时间选择日期，支持分页查看、单条展开和最多 16 MiB 的当日 JSON 导出。没有定时日摘要；导出保留请求及响应正文，省略本地对话标题。
- 16 外部模型入口使用独立预算，显示金额、上限和暂停状态。外部费用未知时保留实际返回（限 256 KiB 的 JSON 对象）与预占，暂停外部入口。当前核账命令仍只操作原有 Agent 账本。
