# PR-33 事实与规则包

`fact_propose` 在当前项目生成待核实候选，逐字校验资料版本和页码。请求批准模式先经过浏览器，撤销把候选标为取消。注册人员在浏览器设置处理期限、确认、改写或拒绝。人工改写保存实际核对的新证据。数值须带单位，锁定事实只由负责人修订。旧事实保留版本、来源与确认人。

`knowledge_get` 读取当前项目已确认、未替换且仍有效的事实。每次查询按查询时刻判定是否到期。来源作废、截止时间过去或已替换时停止返回对应事实。工具回执外层的数据级别按修订链来源的当前最高级别确定，重放也复核。规则包按运行固定首次读取的已登记版本。

开发库用 `pnpm knowledge:seed` 发布带「待注册人员确认」标识的 YAML 种子。相同内容可重跑，修改需提升版本。`pnpm db:setup` 同时准备开发种子。正式环境读取注册人员已发布的版本。历史版本与运行引用受数据库变更保护。

FDA 草稿核对了年度注册、列名复核、2027 财年企业年度注册费、美国代理人和代理人变更。适用性和具体履行由注册人员确认。每条规则在种子中记录条款、核查日及官方档案。[年度注册与列名](https://www.ecfr.gov/current/title-21/chapter-I/subchapter-H/part-807/subpart-B/section-807.22) · [美国代理人](https://www.ecfr.gov/current/title-21/chapter-I/subchapter-H/part-807/subpart-C/section-807.40) · [2027 财年费用公告](https://www.govinfo.gov/content/pkg/FR-2026-07-30/html/2026-15335.htm)

## 验收

- `pnpm test:int apps/backend/src/knowledge/knowledge.int.test.ts` 验证规则包版本不可变、运行固定规则包、锁定权限、历史相连、旧来源升密、等待锁时跨有效期的处理、浏览器 Cookie 与 CSRF、候选先批准与撤销。
- `pnpm test:knowledge` 在独立 Linux 验收机用真实浏览器运行维护 Agent 的只读规则包核对。按实际回执核查最终答复的版本、期限、费用、档案出处和待确认状态，再核对固定版本及写入记录。
- `pnpm docs:html` 生成离线文档。通用检查与标准 R09、M02、双通道真实走查纳入完整验收。

## 没做什么

- 候选处理首版提供浏览器 API。知识管理界面及规则包人审发布、回退和权限操作在 PR-42 完成。
- M02 的真实登记与列名检索、期限提醒及定时唤醒进入 PR-34。候选当前接受项目资料的一处逐字证据，公开核查回执在后续能力中接入。
