# PR-32 R09 申报一致性检查

R09 开发草稿可按用户选择做单项或整包核查。整包通过 R0–R7、五组资料取证和候选复判汇总差异。每项送审差异保留两处实际原文证据，未解析、缺件和接触时长等事项单列。写入交付文件后从浏览器审核，正式发布仍待注册人员审阅。

技能来源包括 SY-QP-15 A3 第 5.3、5.5–5.7 节、《设计开发输出清单》《设计验证记录》《设计开发转换清单》，以及需求 R09 和技术方案 8.2。公开编号用已有 V2 工具，数字或范围可通过显式 `quantityCheck: true` 做 V7 复算。已识别单位分类型换算，引用须实际含值和单位。[D-064](../决定记录.md#d-064-r09-取证与可重放评测)
