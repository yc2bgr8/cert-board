## PR-27 审核卡、证据和工作区文件

## 做了什么

- 从对话和待我处理打开正式八部分审核卡。显示 Agent 的过程判断、关键依据、自检、不确定事项和工作区版本。
- 「通过」及「退回修改」使用浏览器审核接口。退回填写原因。版本过期或服务端冲突后，刷新供人重新核对。通过后显示服务端冻结回执。
- 依据打开指定资料版本及页码的解析文本，并按实际摘录高亮。两处不同位置可并排看。Word 提取单元与 PDF 页码分别标注。
- 改动和项目文件入口读取真实版本，可看文本差异、下载已保存文本。项目资料入口展示已有解析版本，原件位置与解析范围按接口标记。
- 剧本验收使用实际 L08 T1 解析页和同一个 Pi 内核。日常浏览器保留持久账本的计量停止状态。

## 没做什么

- PDF 原页图像、Word 和 Excel 版面、原始文件下载依赖 PR-17。文本证据页按解析文本显示。
- L08 压缩包或文件夹上传、进度及导入报告依赖 PR-19，仍按主路径约定用 T1 种子。人工上传改稿生成新版本等待配套写入接口。
- 此次对比已保存的工作区版本。工作副本与基础版本的对比、Word 排版或转换后的文本对比待接口。
- 项目资料列表从当前版本第 1 页打开。其他版本、任意页选择、资料类别和低置信页列表留资料服务接入。审核引用按所记录的版本和位置精确打开。
- 审核的修改后通过、追问、转交等待业务接口。对话中的修改意见可交给 Agent 重提。
- 真实浏览器送审待 PR-D2 合并后按授权核账，再复验。已经结算的真实模型调用 39 次，0.026985314 美元。另 1 次用量未知，预占 0.00952992 美元。
