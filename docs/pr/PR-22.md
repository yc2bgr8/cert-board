# PR-22 代码沙箱

对应需求 V1.0 的 3.1、6.3，技术方案 v0.4 的 4.26、4.27。

- Agent 可在专用容器用 Python 处理表格、PDF 和 Office 文档。输入从当前对话可读的工作副本、工作区版本或指定资料版本复制。容器无凭据，程序无网络，每次使用单独临时目录。文件、时间、CPU、内存和并发都有上限。
- 只读运行通过 `code_run`。请求批准和完全允许模式可用 `code_run_save` 将产出保存为工作副本的新文件。已有文件受冲突检查保护，整个批次可撤销。
- 执行事件仅登记代码、输入和全部产出的 SHA-256、耗时及已有的调用标识和数据级别。数据库迁移 `0027` 对历史事件保留空值。

## 验收

| 验收 | 结果 |
|---|---|
| `node scripts/sandbox-dev.mjs test` | 实际容器检查非 root、无网络、无凭据、只读输入、资源限额、中文 DOCX 转 PDF、PDF 合并和书签 |
| 真实容器与工具登记的本地合成流程 | 通过。保存三份中文样例产出，逐文件核对登记与读回的字节数，撤销后全部从工作副本消失 |
| Agent 与执行记录集成测试 | 用剧本模型通过真实运行入口读工作区文件，核对执行事件中的三个哈希和耗时 |
| 实际中继的并发和请求中断 | 首个任务运行时返回 429，断开后任务提前退出，下一个请求在 4.5 秒内成功 |
| `pnpm dev:isolated:web:up` 与容器内调用 | 应用容器健康，工作进程经过固定中继执行合成计算；程序创建网络套接字被拒绝 |

只使用合成数据和剧本模型，真实模型调用费用为 0 美元。
