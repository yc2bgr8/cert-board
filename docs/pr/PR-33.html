PR-33 事实与规则包

fact_propose 在当前项目生成待核实候选，逐字校验资料版本和页码。请求批准模式先经过浏览器，撤销把候选标为取消。注册人员在浏览器设置处理期限、确认、改写或拒绝。数值须带单位，锁定事实只由负责人修订。旧事实保留版本、来源与确认人。

knowledge_get 读取当前项目已确认、未替换且仍有效的事实。来源作废、截止时间过去或已替换时停止返回对应事实。读取和重放按修订链各来源的当前最高数据级别处理。规则包按运行固定首次读取的已登记版本。

开发库用 pnpm knowledge:seed 发布带「待注册人员确认」标识的 YAML 种子。相同内容可重跑，修改需提升版本。pnpm db:setup 同时准备开发种子。正式环境读取注册人员已发布的版本。历史版本与运行引用受数据库变更保护。

FDA 草稿核对了年度注册、列名复核、2027 财年企业年度注册费、美国代理人和代理人变更。适用性和具体履行由注册人员确认。每条规则在种子中记录条款、核查日及官方档案。年度注册与列名（外部链接） · 美国代理人（外部链接） · 2027 财年费用公告（外部链接）
