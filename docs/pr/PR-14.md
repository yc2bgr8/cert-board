## 做了什么

- 建立结构化结果、资料库引用与受限检查报告契约，保真保存原文引用。
- V1只统一空白后逐字核对指定版本/页；拒绝不存在、越权、跨项目、作废及占位来源，工作区草稿不能作证据。
- V3核验结构和同项目已发布工作区版本；显式数量/单位不在此切片支持范围，保守拒绝。

- 用L08 T1两处真实摘录验证通过/一字差/换页反例；DOCX定位明确为提取单元。
