做了什么

  • 注册和维护 Agent 都可以在三种对话权限下调用 consult_external_model。核实任务持久登记后由独立通道执行，结论经脱敏和原文重合检查后返回正在运行的 Agent。人工在群聊补充的意见随分类结果回传。
  • 原对话显示进行中、已完成或暂不可用，点「查看群聊」查看发言。对话「停止」同时让关联群聊结束和整理。
  • 审核卡发起的核实返回原对话，并在「依据」中显示结论、类别和出处。该对话下一次普通运行可读取最近一场已完成的核实，按项目原文判断是否修改或重新提交。审核决定仍由浏览器记录。
  • Cursor 失联、默认模型未配置或整场没有可用模型回复时，Agent 可以继续使用项目资料，并收到保留不确定事项的提示。群聊最长等待十分钟，原对话保留继续查看的入口。
  • 按原对话、运行与工作区中的最高资料级别拦截关联保密请求，派发前复查。外部发言回传为参考资料，原权限和审批来源仍由后端核验。

没做什么

  • 原对话会立即显示审核发起的核实结果。结果作为下一次正常运行的参考，自动另起 Agent 运行未接入。原因和后续记录见 D-039。
  • 保密对话的独立改写与本地模型检查待 PR-D3。当前关联保密对话保留本地记录并暂停派发。
  • 出处链接和类别随群聊回传。官方来源的抓取、逐字核验及失败降级待 PR-D5。
