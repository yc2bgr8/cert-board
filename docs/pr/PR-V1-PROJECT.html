PR-V1-PROJECT 新建注册项目

注册人员从「注册项目」旁的「新建项目」建立空白项目。名称和目标市场必填，申报路径可留空，由系统记录为「待研判」。创建成功后打开项目主页。刷新页面会回到该项目，可从「文件」看工作区第 1 版，从「创建项目对话」开始首轮立项。对话预选当前项目及唯一的活动目标，首条消息仍由注册人员在对话中确认发送。

项目负责人是当前登录成员。美国及美国与加拿大项目使用美国东部法域时区，加拿大项目使用多伦多时区。后台按现有浏览器身份、同源与 CSRF 校验写入。项目、注册立项目标、带通用说明的第 1 版工作区和创建回执一起提交。同一成员用同一请求编号重试时取回原项目，改换内容会收到冲突提示。
