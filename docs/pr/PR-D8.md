# PR-D8 技能回退提案

后台按当前生效的技能版本统计审核退回率。默认至少十张已处理审核卡，退回率达到 50% 时生成回退提案。注册人员可以在「设置 → 技能版本」调整这两个值，更新记录进入审计。统计窗口和上一版比较按决定 D-061 执行。[统计范围](../决定记录.md#d-061-技能回退的统计范围)

「待我处理」里的技能回退提醒可打开对应的设置卡。卡片显示技能版本、样本数量和日期、退回率、上一版历史比例与近期内部退回原因。注册人员在浏览器批准后，沿用 PR-24 的回退服务。驳回后至少新增十张已处理审核卡才可能再次提案。没有上一版时仅显示提醒。[v5 第 1.3 节](../变更单/需求变更单_2026-11-20_核实续跑与外发结果.md)

独立 Linux 诊断虚拟机通过六项技能集成测试、lint 和 typecheck。专项命令 `pnpm test:int apps/backend/src/skills/rollback.int.test.ts apps/backend/src/skills/versions.int.test.ts` 涵盖最低样本、阈值、并发扫描、驳回再取样、浏览器回退、提醒、通知配额和阈值审计。`pnpm test:e2e` 使用合成样本通过浏览器阈值设置、从「待我处理」进入对应提案、批准和更新通知。标准真实模型走查随干净快照全套验收执行。
