PR-02 数据库基础

做了什么

  • Drizzle定义与可审阅0000 SQL：app_user、role_binding、web_session、audit_log、legal_entity、entity_role。
  • 审计UPDATE/DELETE/TRUNCATE保护；只读无登录角色只授权两张业务表，不暴露密码和会话秘密。
  • 迁移执行器校验历史SHA-256、按编号互斥执行、事务回滚；生成、审阅、执行命令分离。
  • 开发五角色账号，Argon2id哈希，密码仅来自.env.local；幂等且不重置已有账号；拒绝接管非开发同名账号；生产拒绝种子。
  • 测试使用本次独有的随机临时数据库，结束后清理；补充数据库说明及启动步骤。

没做什么

  • 登录和浏览器会话接口留给PR-04；业务台账和领域服务留给PR-05。
  • 不初始化真实法律主体或法规期限，避免虚构业务数据。
