## PR

PR-12 模型网关、强制代理与真实工具调用

## 做了什么

- YAML严格配置与OpenAI文本/工具调用协议，真实模型仅启用指定Flash；配置、请求和输出均有边界校验。
- 每次调用重查身份和最高资料级别，保密资料拒远端；预占预算后仅新请求可派发。先记录用量，再校验消息，异常不丢已知费用。
- 显式代理传输，无直连回退、无自动重试或重定向，限制输入输出大小，取消传入在途请求。
- 前置PR-13最小Squid代理：仅既定域名CONNECT443，拒其他目标、私网及保留网段；非root、只读、无凭据、独立网络和回环端口。
- 真实测试共用日常持久账本；仅合成文本，返回指定只读工具调用，不进行外部业务操作。

## 没做什么

- 上游token流式输出、备用模型与自动重试、图像输入、本机测试HTTP接口未开放。
- 模型配置数据库表与维护页延期，当前只有一个YAML配置来源。
- 尚未配置保密资料的本地模型，因此保密请求全部拒绝。
- Windows宿主进程OS级出网封锁、解析/沙箱/抓取网络分段仍属PR-13后续范围；不能声称主机所有流量已封锁。
- Agent内核与浏览器对话仍在后续PR接入，本PR真实验收只证明网关工具调用。

## 新增依赖

- yaml 2.9.1，ISC；无运行时依赖或安装钩子，无默认网络请求。
- undici 7.30.2，MIT；无运行时依赖和npm安装钩子，源码有开发prepare；只使用显式ProxyAgent，无SDK/遥测输出。
- Squid 6.14（Ubuntu官方固定包版本），GNU GPL及镜像版权文件所列条款；不解密TLS，不带凭据，不启用遥测。镜像摘要、DNS临时映射和验证记录见代理README。
