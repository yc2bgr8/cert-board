## PR-21 双 Agent、资料和工作区工具与批准续跑

## 做了什么

- 按项目所属 Agent 读取固定开发定义和技能索引，共用 Pi 内核、模型网关和对象权限。注册使用 R09，维护使用 M02。两个技能均标为开发草稿，待注册人员确认。
- 接入资料检索、原文分页、技能加载、工作副本的列出/读取/搜索/写入/编辑、保存/恢复/重基、计划和提问。工具复用 Registry 事务，资料读取提供可用于 V1 的完整回执，过程事件提供有界摘要。
- 浏览器的批准和拒绝产生继续票据，后台在原运行上核对冻结调用并一次性执行或回传拒绝原因。Pi 使用原回执继续，同一运行计量累积。队列重放、停机和租约保持原边界。
- 北京时间周六、周日暂停催办，周一至周五按同事项同收件人一天一次。旧积压跨日失效。迁移 0013 加入保护，开发消息只使用现有本地测试通道。

## 没做什么

- `doc_import` 等解析及整包导入依赖 PR-17、PR-19。期限计算和提醒规则依赖 PR-15。完整业务记录查询及写入和通过 Agent 新建项目的流程随相应业务 PR 接入。L08 主路径使用现有项目及种子资料。
- 本 PR 登记提问并暂停，剧本验证下一条回答在同一对话进入相同内核。浏览器答案提交和通知、对话权限切换、进度显示随后在 PR-25/26 接入。
- Agent 与技能发布管理留 PR-24，后续接入完整评测及正式审阅。法定节假日日历、非登录收件人目录、日摘要及真实消息渠道后续验收。
- 真实模型读、写、保存已由现有工作区及读取回执验证。真实自动送审未完成。测试遇到 token 上限及上游计量问题，等待核账后复验。基于相同内核的剧本模型覆盖了提交及批准续跑。
