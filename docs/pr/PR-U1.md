# PR-U1 外框与视觉

依据为 v3 的 01、02、13 设计稿和共用 `cb.css`。登录、新对话、搜索、助手侧栏、项目顶栏和右栏框架采用青绿主题与 Logo 方案 C。设计变量定义于 Tailwind 4 主题。Inter 和 JetBrains Mono 使用本地打包的 Fontsource 文件。

## 验收

- 本地 lint、类型检查、394 项单元与构建通过。
- 本地完整集成 390 项通过。
- 30 项隔离库浏览器验收通过，覆盖助手切换、新对话默认模式、搜索键盘操作及既有完整对话和审核流程。
- 新对话、搜索在 1280 宽无横向溢出。浏览器外部请求、页面错误和 CSP 违规均为 0。真实模型调用 0 次。
- 复审后补齐项目外默认注册 Agent、表单与顶栏 Agent 同步、选中项自动滚动、组合框和列表框语义及发起人显示。浏览器以多条结果验证方向键选择及回车打开目标，单元回归覆盖异步插入对话结果时按记录 ID 保留原选择。
- 1000 宽开合侧栏保留新对话输入。单元回归验证取消新对话后文件和资料标签页保留同一节点。

## 依赖

`@fontsource/inter@5.3.0` 和 `@fontsource/jetbrains-mono@5.3.0` 均为 OFL-1.1，安装包无生命周期脚本。实际引用为字体声明及本地 WOFF/WOFF2 资源。浏览器验收在零外部请求下检查本地 Inter 已加载。[Fontsource 安装文档](https://fontsource.org/docs/getting-started/install)
