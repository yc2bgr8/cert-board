# PR-46 R04 适用法规标准与证据规划

## 本机候选范围

- 增加可登记的注册 Agent 技能草稿。它指导登记候选依据的版本、FDA 认可范围和过渡期，按证据原文核对实际型号、尺寸、配置与接受准则。需要付费条款原文的地方标为「待提供标准原文」。
- 美国公开来源按 v7 K07 纳入技能正文，供 `web_fetch` 存档后逐字核对。口内和 CPAP 证据清单都须连回项目资料，市场和路径从已确认的上游结果取得。[FDA 共识标准指南](https://www.fda.gov/regulatory-information/search-fda-guidance-documents/appropriate-use-voluntary-consensus-standards-premarket-submissions-medical-devices)
- `fixtures/r04/scenarios.json` 保存两份合成输入。口内题取 E04 的证据类别口径，保留大号报告向小号延伸的缺口。CPAP 题分基础版和无线版，保留数据接口和试验缺口。评测期望在测试端，输入中只含问题与设计、报告摘录。

## 开发验收

- `pnpm eval:r04` 核对技能草稿的登记格式、官方出处、合成题的证据类别与引文，以及缺少代表性说明、接受准则或引用晚于回放时点的资料时的判分。隔离虚拟机上的类型检查、lint 和 3 项专项测试通过。
- 开发环境用 `pnpm skill:stage 'skills/R04-适用法规标准与证据规划/SKILL.md'` 登记草稿。隔离验收数据库中重复登记两次只存一份草稿，发布记录为零。人在浏览器打开技能版本审核，确认后按现行流程发布。
