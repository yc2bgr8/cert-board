## PR

PR-01 本地依赖服务与后端骨架

## 做了什么

- 独立 cert-board Compose 项目、PostgreSQL16/pgvector、MinIO命名卷、单独测试库；Node脚本经WSL启动，Linux直接调用Docker。
- 只传递数据库/MinIO必需凭据，模型密钥不进入容器；配置初始化生成随机密码，已有值保持不变。
- Fastify API与worker两入口；共享zod配置及响应模式；依赖真实健康检查、超时和优雅关闭；安全中文错误。
- Pino递归脱敏，包含child/setBindings最终输出边界；不打印原始异常、请求、配置值。
- 单元及集成测试；CI增加依赖启动和集成测试，仍无模型密钥与L08原始资料。
- 因本机Docker内部网端口发布限制，提前实现最小开发中继，保留依赖服务的无出口内部网络，见D-006。

## 没做什么

- 业务表、登录、Agent、界面留给后续PR；worker此时仅写心跳。
- 沙箱、解析、抓取中继网段及模型出网代理留给对应PR；不登记代码执行工具。
