# PR-35 运行评测与隔离回放

结构化提交产生任务完成、答案质量、依据充分、工具可靠、策略遵守、效率和协作质量七项结果。无审核卡的运行也记录可观察维度。确定性评测使用已有 V1/V3、适用的 V6/V7、工具调用与授权快照、批准记录及运行事件。没有独立依据的陈述进入「需复核」。审核卡的「自检」可以展开评测结果。评测存档故障保留原审核卡并记录故障类型，注册人员可从卡片重试存档。[决定 D-067](../决定记录.md#d-067-运行评测与隔离回放)

V5 使用已配置且与任务模型不同家族的本地端点。模型只返回有限的维度结论，结果只能降低确定性评测。回放以录制的资料库页和官方回执为输入，经同一 Pi 内核运行。提交给模型前遮挡目标身份、K 号和加拿大许可号。网页能力不进入回放工具目录。官方记录按生效日期截断，未来的文件页无法读取，越过回放边界的依据作废。

## 验收

- `pnpm eval:agent` 验证七维评测回放一致、独立模型家族、无回执时降级、回放遮挡、截至日期、网页工具关闭和依据作废。
- `pnpm test:int apps/backend/src/reviews/submission.int.test.ts apps/backend/src/api/review-routes.int.test.ts` 检查提交后存档、并发重放、旧数据兼容和评测故障时保留业务提交。
- `pnpm docs:html` 生成离线文档。业务走查和全套测试在独立 Linux 虚拟机执行。

## 没做什么

- 本地复核服务尚待配置。语义复核输出由剧本验证，现有真实走查验证端点不可用时保留审核成果和需复核状态。已结束运行的 V5 独立重试入口待接入。浏览器可对失败的确定性存档独立重试。
- 已录制的回放夹具供框架验收。完整评测集、模型训练截止分集和人工抽核进入后续评测 PR。
