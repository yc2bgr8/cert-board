# PR-D5 外部结论的出处核对

范围见 v2 附录 B.2、v4 附录 B.2 和 v4 §1.8。引用机制沿用技术方案 v0.4 的 V1 检查和网页存档。

## 做了什么

- 外部模型应给出公开网址和逐字摘录。核实 worker 复用网页抓取和项目存档，检查摘录是否存在。核对通过保留资料编号、版本、提取单元和原件哈希。无法查证的意见保留待核实。
- 审核卡从核实结论打开站内证据查看，提供已核对原文高亮和原件下载。历史证据在打开结论时重新核对资料状态，无效资料不再提供审核依据。
- 有本地主模型时，Cursor 派发之前用模型网关执行本地检查，且仍沿用程序检查、保密字词替换和最终派发复核。

## 验收

- 集成测试覆盖同一项目的原文匹配、找不到摘录、链接不可用和资料作废。另验证关联目标取消后不入库、单一归档失败继续检查其他地址、缓存中的其他摘录、本地检查不发送及本地检查的完整文字。
- 同一抓取服务实测已批准的公开模型目录。存在的摘录通过，合成假摘录拒绝，存档哈希一致。真实模型调用 0 次。
- 界面测试验证未核对出处没有审核证据入口。浏览器使用 1440×900，沿用设计稿 05 的核实卡布局和 06 的原文视图。网页单一出处用一栏，保留地址类别、北京时间、下载和原文高亮。完整资料编号可在短编号上查看。[审核卡 05](../evidence/pr-d5-05-review-verification.png) · [证据查看 06](../evidence/pr-d5-06-source-evidence.png)

## 没做什么

- 独立群聊未选择项目时保留待核实，需要项目上下文才可归档。保密内容的本地改写、真实公司端点联调待本地服务，按 X4 留空。当前关联保密对话继续拒绝自动外发。
- PDF 原件可归档，逐页文本核对待 PR-17。摘录核对不推断事实含义，业务结论仍由注册人员审核。
- 真实公司模型可用后再做本地出网检查的实机评测。本 PR 不新增模型或依赖。
