# PR-52 V1 指标与试用准备

## 本机候选范围

- 依据需求 8.6 和 8.7、v7 D19 与 D20，建立本机脱敏测量输入和 21 项分项结果。指标输出包含候选提交、验收时的 `main`、合并树、样本数和证据标识。基线、达标、未达标和证据不足分别显示。
- `pnpm measure:v1 <脱敏测量JSON>` 读取同一候选的汇总，`pnpm test:v1-measure` 只运行固定合成样例。输出的 `scope` 标注合成、离线开发或正式汇总。正式验收结果仍按现行虚拟机报告、自查、独立复审和合并规则确认。
- 提供 [V1 试用说明](../V1试用说明.md)，包含两天实际体验、现有地址与开发账号、成果用途、审批、匿名反馈和严重问题上报。
- 在既有浏览器剧本中记录点击发送到首次出现计划、以及打开新对话和搜索的时长。证据标为 `scripted-browser`，供离线开发判断；正式时长须在合并候选用真实模型和浏览器复测。

## 输入和判分

- 输入顶层含 `scope`、`head`、`main`、`tree`、`observations`。每项观测包含 `evidence` 和 `data`，证据用脱敏标识并与本机原报告对应。正式范围另须用 `evidenceIndex` 为每个标识登记正式范围、候选、基线、合并树，同次指标不能借用其他树和离线证据。参考格式见 `fixtures/v1/measurement-synthetic.json`。
- R09 已知问题以 RV-05 的 8 条为分母，至少发现 7 条。注入缺陷与原文程序核对都需 100%。误报由注册人员确认后记录基线。
- M02 核对决定、列名、企业注册、代理人、申请人注册、品牌、UDI。M01 导入比较行记录和人工抽查，提醒与期限单测按各自样本核对。台账问答以已启用模板的基准和范围外用例判分。
- S01 事实出处需要全覆盖。一次审核通过率为基线。L08 的 E01、E02、E03、E04、E23 按已知答案逐项比较。CPAP 记录注册人员独立判断和结果对照的基线。
- 系统按样本计算非模型失败率，上限 2%。首次显示工作过程及界面动作分别取最近秩的第 90 百分位，达到 5000 和 1000 毫秒仍通过。安全按需求 8.6 的六组逐项提供证据，严重发现阻塞判分。人员评价和周主动使用天数留基线。

## 开发验收

- 隔离虚拟机型检、lint、5 项专项通过，CLI 验证了固定合成样例的 21 项口径。缺失证据维持待测，严重问题阻塞判分，正式范围拒绝离线证据及其他合并树。
- 真 Chromium 的剧本开发样本中，一轮首次计划显示为 885 毫秒，打开新对话与搜索为 97、65 毫秒。记录了范围、定义和样本数，正式系统指标等待统一候选复测。

## 没做什么

- 当前各功能候选的离线证据属于各自提交。正式指标必须在依赖通过并形成同一合并树后按真实范围测量。全量真实测试、实际两天试用及 PR-52 合并仍待完成。
