  • Agent 可在专用容器用 Python 处理表格、PDF 和 Office 文档。输入从当前对话可读的工作副本、工作区版本或指定资料版本复制。容器无凭据，程序无网络，每次使用单独临时目录。文件、时间、CPU、内存和并发都有上限。
