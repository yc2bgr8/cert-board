## PR

PR-08 工具登记、动作级别、幂等与撤销

## 做了什么

- 参考RV02判定语义重新实现默认拒绝策略，不移植其原始参数日志或Harness审批方法。
- 冻结静态发布工具目录，按角色/范围/模式/目标筛选，强行调用同样检查；不可逆/审批拒绝，external绝不调用execute。
- Agent与浏览器身份分开；工具允许角色及对象范围使用同组绑定，回调权限同步收窄，审计作者不伪称浏览器人操作。
- 新0004前置运行身份表和幂等/私有会话回执/撤销表；业务、原值、版本和回执同事务。重复调用不重复效果、变参拒、失败回滚，撤销不覆盖后续改动。
- 源资料和工作区级别刷新、最高级别传播；旧缓存不能绕过升密或作废。快照规范化一次并冻结，写入必须推进版本。

- 实际项目/工作区业务工具在PR-21接入，必须先适配共享tx；当前没有公开工具执行或写入HTTP入口。
- external目前只返回明确的待接入结果或本地测试提案工厂，正式提案/审批队列在PR-09接入；没有实际外发。
- 完整Agent内核、工具说明的Agent行为回归和技能评测待PR-20/21；`eval:agent`/`eval`实际输出尚未实现，不算通过。
- 完整目录内容审阅发布留PR-24/42；当前静态已发布登记版本。run事件、保留策略和执行权后续补齐。
