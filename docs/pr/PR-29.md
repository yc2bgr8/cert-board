# PR-29 Agent 评测运行器与真实回归基线

默认的 `pnpm eval:agent` 读取场景清单并执行同一个 Pi 内核。新增合成 L08 资料读取、工作区保存和送审、版本冲突提问、M02 缺凭证及核实回执续跑。保留内核已有的插话、停止、审批等待、历史和预算回归。[场景清单](../../evals/agent/scenarios.json)

`pnpm eval:agent --integration` 复用隔离 PostgreSQL 测试中的真实 Agent、相关工具和对话命令场景，额外覆盖子任务证据冲突、工作区版本和负责人离线唤醒。默认无界面剧本无需测试库，多场景的业务存储和权限验证使用集成命令。

按 v6 使用选定的 GPT-6.2 Astra Pro。`pnpm eval:agent:baseline` 从通过的独立虚拟机报告和同提交的标准走查回执生成脱敏摘要。初始观测以已合并 PR-D8 的实际走查为参考，后续真实回归沿用同一入口。[真实回归基线](../evidence/Agent真实模型回归基线.md) · [v6 调整](../变更单/需求变更单_2026-11-20_可用优先.md#pr-29-调整)

独立 Linux 诊断通过 35 项无界面剧本、61 项专项集成和 6 项运行器与基线单测。PR-D8 原始验收记录有两条业务路径、335 秒和 2.7528364 美元结算，作为历史观测保留。运行器及基线测试覆盖验收目录、时间窗、各轮回执及摘要、对话身份和账本。最终候选在干净快照执行通用检查、文档专项和标准真实走查，并用本轮回执生成回归摘要。
