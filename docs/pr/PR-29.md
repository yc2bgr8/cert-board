# PR-29 Agent 评测运行器与真实回归基线

默认的 `pnpm eval:agent` 读取场景清单并执行同一个 Pi 内核。新增合成 L08 资料读取、工作区保存和送审、版本冲突提问、M02 缺凭证及核实回执续跑。保留内核已有的插话、停止、审批等待、历史和预算回归。[场景清单](../../evals/agent/scenarios.json)

`pnpm eval:agent --integration` 复用隔离 PostgreSQL 测试中的真实 Agent、相关工具和对话命令场景，额外覆盖子任务证据冲突、工作区版本和负责人离线唤醒。默认无界面剧本无需测试库，多场景的业务存储和权限验证使用集成命令。
