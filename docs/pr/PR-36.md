# PR-36 评测集与回归准备

从已授权的参考快照迁入组长认证线 120 个示例，六类各 20 个。用例、原剧本和判分保留在 `evals/cert-line/`。校验适配使用后端已有的 Zod 版本，函数来自参考项目的对应认证线实现，供本仓库离线回归使用。

`pnpm eval` 运行同一 Agent 内核的剧本、R09 回归、现有一致性规则与数值单位校验，以及认证线示例。它复用既有无密钥的评测进程环境。

M02 专项在隔离测试库用 `pnpm eval:m02` 执行，同样纳入 `pnpm eval --integration`。合成回执覆盖 UDI 有匹配、成功零条和来源失败。浏览器启用定时核查并退出，后台用既有扫描器唤醒维护 Agent，读取存档、计算站内提醒日期、保存报告并送审。检查实际审核卡引语、七个持久化评测维度、模拟用量、注册人员的浏览器审核和零外发。来源失败留在待核实项，FDA 到期年份填为文本并逐字引用数字原文。

`pnpm eval:cert-line:compare` 检查完整用例覆盖后，输出与 Flash 116/120 分组基线的差值及本次未达标用例。提供同口径逐例报告时，可核对具体用例的状态变化。参考快照只有 Flash 的分组汇总，逐例对照待原报告或新实测数据。[基线说明](../../evals/baselines/README.md)

E07 在 T1 内存副本去掉清洁验证报告及重复件、替换一处型号，并把一份报告的储存期限改成 3 年。判分核对 eSTAR 引用、型号和清单原文、以及两份报告的储存期限，拒绝漏项和假引文。离线剧本用同一 Pi 内核读取录制资料并校验判分。真实检出率须另跑具备授权和资料隔离的正式回放。[评测要求](../参考/需求文档_V0.4/AI原生器械认证与设计开发协同_需求文档_V0.4.md#153-注册线评测)
