注册 Agent 和维护 Agent 可用 official_lookup 查询精确编号，经现有公开抓取服务访问 openFDA、AccessGUDID 和加拿大 MDALL。可写会话生成带查询时间、资料编号、版本和定位的公开存档。只读会话允许查询和读取已有存档。缓存按项目、截止日和页隔离。FDA 的限定查询通过决定日期过滤，MDALL 按许可证签发、器械及型号的加入和移除日期过滤。返回记录无可证实的历史版本时，工具提示查阅早期存档。D-062
