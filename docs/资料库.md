# 资料库与T1开发种子（PR-06）

当前资料入口为开发种子，运行 `pnpm db:setup` 后L08项目具备59份来源身份、664条逐页记录。相同快照重复执行不追加版本；同一快照身份却传入不同内容时拒绝。新的快照追加新版本，旧版保留且不能覆盖。回放旧快照不会把最新版本切回旧版。

`document`保存项目、稳定来源编号（D001～D059）与作废状态；`document_version`保存不可变内容、级别和来源快照；`document_page`保存逐字文本、页码、解析方法、OCR信息。版本和页禁止UPDATE/DELETE/TRUNCATE，资料不可删除，后续只允许登记作废原因。名称/路径在比较和长度校验前做NFC，正文不规范化或折叠空白。

哈希必须区分：

- `original_sha256`：T1清单中的原文件哈希，本次没有读取原文件重算。
- `content_sha256`：实际存入私有MinIO的解析JSON内容哈希，由程序计算；读取时重新校验。
- `source_snapshot`：本次documents.json和pages.jsonl快照指纹。

本次未保存原始PDF或Word。“版本1”只表示本次导入版本。原文证据展示为解析文本；Word的页号是抽取单元。D014占位页拒绝作为正文，不能声称eSTAR表单已解析。低于0.9的OCR置信度会提示核对原件；本快照两条为D005/D017第2页0.812。

仅读接口：项目资料列表、资料详情、版本列表、逐页读取和项目内关键词检索。每次先校验浏览器身份及项目/资料范围；资料列表最多50、检索最多30条且摘要不超过300、正文最多12000码元，均返回续读位置。作废和占位页不作为检索证据。返回正文或摘要时包含资料/版本/页定位与资料级别；同一资料的历史最高级别向所有读取传播。

主路径验证证据来自同一D035的第1和第5页：两处K号写法不同。这里只确认资料中的写法差异，不能由出现次数决定正确号码或对比器械适用性。

单文件上传、原始文件和原页显示、人工作废操作尚未接入；模型工具在PR-21登记。存储事务失败可能留下无引用的私有内容对象，不能因此删除已有引用的同哈希内容，后续另做受控回收。
