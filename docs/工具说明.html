check_run（builtin-checks-v1）

动作级别：read；角色：RA、RB、GM；模式：read_only、execute。

做什么：提交审核前核对结构化结果与资料库原文；当前执行V1原文逐字核验和V3结构检查。

何时使用：已有doc_read取得的真实引用和本项目已保存工作区版本，准备检查交付时使用。

何时不用：不要用它代替doc_read或法规判断；它不证明模型实际读过，不验证哪个K号正确。通过后仍须submit_for_review，审批只能由人在浏览器完成。

参数：直接传skill、workspaceVersion、conclusion、claims、evidence、missing、uncertain、nextStep。引用只用documentId/version整数/page/quote；禁止草稿路径。K号是字符串且unit为null；数量/单位转换暂未支持。例子为虚构格式，必须替换成真实资料与版本。

示例仅为格式，不是实际证据：

{
  "skill": {
    "id": "R09",
    "version": "0.1.0"
  },
  "workspaceVersion": "10000000-0000-4000-8000-000000000002",
  "conclusion": "虚构格式示例，实际结论须依据读取资料。",
  "claims": [
    {
      "id": "C1",
      "object": "对比器械",
      "field": "predicate_k_number",
      "value": "EXAMPLE-001",
      "unit": null,
      "sources": [
        {
          "documentId": "10000000-0000-4000-8000-000000000001",
          "version": 1,
          "page": 1,
          "quote": "EXAMPLE-001"
        }
      ],
      "status": "checked"
    }
  ],
  "evidence": [
    {
      "documentId": "10000000-0000-4000-8000-000000000001",
      "version": 1,
      "page": 1,
      "quote": "EXAMPLE-001"
    }
  ],
  "missing": [],
  "uncertain": [
    "正确编号需业务人员核实。"
  ],
  "nextStep": "核对原件后提交审核。"
}

当前检查不会证明资料事实正确或模型实际读取过。Agent与技能评测在PR-20/21接入同一内核后运行，占位命令不算通过。
