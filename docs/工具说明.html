工具说明

以下为当前登记工具的完整模型说明。其他通用/业务工具在PR-21接入。所有部门成员业务权限相同；过程批准只由对话发起人在浏览器处理。approvalInAsk=false不免除外部提案逐条审批或最终审核。

check_run（builtin-checks-v2）

动作级别：read；模式：read_only、ask、full；请求批准模式先问：否。

做什么：提交审核前核对结构化结果与资料库原文；当前执行V1原文逐字核验和V3结构检查。

何时使用：已有doc_read取得的真实引用和本项目已保存工作区版本，准备检查交付时使用。

何时不用：不要用它代替doc_read或法规判断；它不证明模型实际读过，不验证哪个K号正确。通过后仍须submit_for_review，审批只能由人在浏览器完成。

参数：直接传skill、workspaceVersion、conclusion、claims、decisions、evidence、missing、uncertain、nextStep。decisions必填，没有过程判断时显式传[]；每项含id/subject/choice/alternatives/reason/sources/risk(low或high)，至少一条原文。陈述与判断合计最多20条，全部引用合计40条。引用只用documentId/version整数/page/quote，禁止草稿路径；K号是字符串且unit为null，数量换算未支持。V1只核验引文，不证明判断正确。例子为虚构格式，必须换成真实定位。

submit_for_review（builtin-review-v2）

动作级别：reversible_write；模式：ask、full；请求批准模式先问：否。

做什么：把已保存的核查报告和结构化证据提交给人审核；仅建立待审核卡，不会批准或冻结版本。

何时使用：已按技能读取实际资料、完成报告、保存最新工作区版本并用check_run通过关键检查后使用。

何时不用：不能当作审批工具；对话中的同意不算批准。资料未读完整请先doc_read，保存冲突先合并；程序不判断正确K号或法规立场。

参数：直接传结构化结果的skill/workspaceVersion/conclusion/claims/decisions/evidence/missing/uncertain/nextStep。decisions必填，可显式[]；每项记录id/subject/choice/alternatives/reason/sources/risk(low或high)，至少一条原文。所有判断与陈述引语都须完整出现在本对话成功doc_read回执；陈述与判断合计20条、全部引用40条。最少证据和卡片风险仍由服务端策略确定，判断风险不能降低检查要求。例子为虚构格式，请替换成真实定位。

propose_external（builtin-proposal-v1）

动作级别：external；模式：ask、full；请求批准模式先问：否。

做什么：为明确的外部动作建立待人工审核提案；开发环境仅支持本地测试渠道，绝不直接发送。

何时使用：用户明确要求准备对外内容，且已有本项目登记的测试联系人时使用。

何时不用：核查结果交人工审核请用submit_for_review；没有登记联系人不要猜编号；审批只能在浏览器审核卡操作。

参数：contactId是本项目有效登记联系人编号；subject是单行主题；body是待审核正文，不支持附件。

格式示例（不是真实业务数据）：

{
  "contactId": "00000000-0000-4000-8000-000000000001",
  "subject": "资料核对（虚构示例）",
  "body": "请协助核对资料。此编号仅为格式示例，实际须使用登记联系人。"
}

queue_internal_message（builtin-internal-v1）

动作级别：reversible_write；模式：ask、full；请求批准模式先问：是。

做什么：为已登记并绑定身份的内部同事排入本地测试消息；不直接发送，不支持真实渠道。

何时使用：资料请求或催办对象为本项目已绑定的开发成员；请求批准模式先等浏览器批准，完全允许模式直接排队。

何时不用：公司外部对象必须用propose_external逐条审核；未知联系人不要猜地址；最终工作结果用submit_for_review。

参数：contactId使用登记联系人编号，subject是单行主题，body是拟发送正文；不得传地址、身份绑定或批准字段。

格式示例（不是真实业务数据）：

{
  "contactId": "00000000-0000-4000-8000-000000000001",
  "subject": "核对资料",
  "body": "请核对资料。此联系人编号仅为格式示例，必须换成实际登记编号。"
}

检查不证明事实或法规正确；提交审核另验实际读取回执。内部测试队列当前仅接受已绑定的活动开发成员，发送前复核状态/版本/级别/日期；没有任何真实发送函数。

同一Pi内核的剧本回归已接入eval:agent；完整技能业务评测仍在PR-21/29继续，不能把占位eval当作通过。
