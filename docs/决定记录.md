## D-006 本机 Docker 的内部网络端口发布

PR-01 实测 Docker 29 的 internal 网络不发布宿主机回环端口，即使容器健康，Windows 仍无法连接。为保留数据库和文件存储无出口的内部网络，在 PR-01 提前加入最小开发中继：中继连接内部网络和本项目的转发网络，仅转发三个固定 TCP 端口到数据库和 MinIO，发布端口均绑定127.0.0.1。PR-13 后续再扩展解析、沙箱、抓取的独立网段；不通过让沙箱联网解决开发连接问题。

## D-007 身份与审核权限的保守默认值

PR-04浏览器会话默认12小时，最大24小时；写操作同时要求本站Origin、浏览器请求标记、Cookie及CSRF（登录尚无Cookie时要求Origin和JSON）。令牌只存哈希，开发账号在生产环境拒绝登录。

动作按角色及同一条授权范围共同判定。对话和销售请求必须属于当前用户；技术维护操作只允许全局TECH。审核必须声明类型：注册人员职责范围（含维护）用registration，仅RA/RB；管理决策用management，仅GM；不明类型默认拒绝。审核卡在PR-16接入这些规则。

当前单API进程按15分钟窗口限制账号5次、来源IP30次尝试；在异步验证密码前预占次数，成功只清账号次数，不清IP次数。计数保存在进程内存，重启清零；如后续增加多API进程，须先改为共享限速。角色管理界面及角色变更入口/审计留给PR-59，不为本次主路径提前开放。
