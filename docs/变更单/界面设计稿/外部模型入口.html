按 FDA 现行的上市前网络安全指南和 FD&C 法案第 524B 条，能联网的输液泵通常属于“网络设备”，510(k) 里一般要包含：

  1. 网络安全风险管理报告（威胁建模、风险评估）
  2. 软件物料清单（SBOM），列出第三方组件及其支持状态
  3. 上市后漏洞监测、披露与修复计划
  4. 安全架构视图（整体系统、多患者危害、可更新性等）
  5. 网络安全测试报告（含渗透测试）

这些要求同样适用于 De Novo 和 PMA。具体到你们的产品，建议交给注册 Agent 对照项目资料逐条核对。
