cert-board 界面设计稿

本目录是 cert-board 界面的完整设计稿，共 17 页，覆盖需求文档第3章和技术方案第3章的全部页面，另加外部模型核实。设计稿由 Claude 绘制，Lan 确认方向。它是 PR-U1～U4、PR-D6、PR-D4 的开发依据和截图验收标准，见《需求变更单（2026-11-19）：界面重做与外部模型入口》和《需求变更单（2026-11-19，二）：外部模型核实》。

怎么用

  • 每页有一个 HTML（浏览器直接打开）和一张同名截图（1440 宽）。
  • 共用样式在 cb.css，颜色、字号、圆角、间距和组件尺寸都在里面。开发时把 :root 中的变量写进 Tailwind 4 主题，组件按同样的尺寸和颜色实现，不要另起一套。
  • Logo 文件在 logo/。
  • 页面中的项目、K号、人名、金额、时间都是示例，沿用 PR-C2 界面稿的虚构数据，和真实资料无关。
  • 截图验收：每个界面 PR 在 docs/evidence/ 附同一状态的 1440 宽截图，和这里的截图对照，差异写进 PR 说明。

共同规则

  • 左栏 248px，从上到下依次是：
    • Logo；
    • 新对话、搜索；
    • 待我处理（带数量）；
    • 助手：注册Agent、维护Agent、外部模型；
    • 选中的助手下的项目和对话；
    • 底部人名和设置。

窄于 1024px 时左栏收起。

  • 对话内容列最大 760px。右栏 520px，用于审核卡、外发提案、运行详情、核实结论；核实进行中的「本场核实」右栏 340～360px；证据查看和改动对比用宽右栏。右栏可以关闭，Esc 关闭。
  • 颜色的用法：
    • 主色（青绿）只用于主要按钮、选中项、批准请求和待处理数量；
    • 状态色只用于状态标签和检查结果：通过用绿，注意用黄，失败用红，信息用蓝。
    • 核实结论同样用状态色：可信用绿，有分歧用黄，待核实用红，人提供的情况用蓝。
  • 批准请求的卡片在输入框上方，只有发起人能处理。审核卡和外发提案在右栏，任何注册人员都可以作决定。
  • 权限模式在输入框旁切换，新对话默认「完全允许」。
  • 图标统一用 16px 的线性图标，随前端打包。字体用 Inter（@fontsource 打包），中文回落到 PingFang SC、Microsoft YaHei。
  • 按钮和链接用真实的 button、a 元素；焦点要可见；文字对比度符合 WCAG AA。

设计稿没有画的

  • 深色模式：暂不做。
  • 手机端：按需求 D16 另定，窄屏时收起左栏即可。
  • 加载中、空状态、出错：按同一套样式做。空状态写一句说明，加一个主要操作；出错时写清发生了什么、怎么处理。
