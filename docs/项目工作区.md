# 项目工作区（PR-07）

每个项目一个工作区，每次保存生成不可变版本。文件内容仍用私有内容寻址存储；版本保存路径、SHA-256、大小和资料级别，不在数据库重复保存正文。

每个执行模式对话拥有自己的工作副本，只记录相对基础版本的改动。用户不能读写别人的私有副本；保存后的项目版本才按项目范围共享。数据库组合外键阻止对话、用户、项目、基础版本之间的错配。

文件写入要求提供期望旧哈希（新建为null），防止同一文件的过期修改。保存时锁定工作区并核对基础版本；另一对话已保存则409，返回最多20个变动文件及截断标记，保留当前副本。

冲突后显式核对最新版本与草稿版本；有重叠修改的文件还需当前与草稿哈希确认，调用方先读取并整理正文。没有force覆盖。决定记录只允许追加；若两个副本的决定历史分叉，当前版本保留原副本并要求基于最新版本新开对话整理。

恢复操作产生新版本，当前指针不会倒退。决定记录保留最新内容，不恢复成旧历史。资料级别按工作区、版本、文件、草稿、对话的最高值传播，不能通过恢复旧版本或删除草稿内容降低。

路径是经过NFC规范化的相对路径；拒绝上级目录、绝对路径、反斜线、控制字符及Windows设备保留名。文件读取验证哈希并严格解码UTF-8；按完整Unicode字符边界分页。文本/Markdown按行比较，保留行号和换行差异；长行/大文件会明确提示上限，非文本只比较哈希。

初始L08版本包含AGENTS.md、计划.md、问题清单.md、决定记录.md、资料/引用清单.md。引用清单只指向资料库，工作区草稿不能作为事实引用来源。开发种子重复执行不覆盖已有版本；项目说明不植入预期K号答案。

当前HTTP只读：按项目取工作区、列版本和文件、读取文件、查看差异。写入/保存/恢复/冲突处理为待工具登记的内部服务。冻结尚无接口，PR-16只能在人通过浏览器审核卡后执行。
