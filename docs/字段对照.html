9 验收边界

本 PR 应验收：六表迁移；项目自动编号与约束；期望版本冲突时拒绝覆盖；项目/目标按身份和对象范围读取；开发种子幂等且不把同名真实项目当作种子；快照三个变更操作均拒绝；只读角色不能写入。具体已通过的命令与结果记录在 PR-05 说明中。

本 PR 不验收：七张延后表的业务能力、真实法规期限、真实主体或联系人导入、生产种子发布、资料解析、整包一致性检查、已批准工作区冻结、外发、预算计量或目标自动流转。它们必须在相应后续 PR 单独实现与验证。
