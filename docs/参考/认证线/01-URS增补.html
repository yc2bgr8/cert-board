认证线 URS 增补（URS-C）

文档编号：URS-IDP-C · 版本 A0（草稿）· 2026-11-13
增补对象：《研发流程平台 URS》（docs/11-验证与发布/01-URS与测试追溯矩阵.md）
风险分级沿用 MVP：H（影响合规判断或记录完整性）、M（影响效率或提醒）、L（展示类）。

一、通用

编号需求风险对应 PR
URS-C-01认证线是同一个平台的一部分：共用登录、权限、审计、文件存储、任务队列和模型网关；可以用开关 CERT_LINE_ENABLED 整体关闭MPR-48
URS-C-02认证线角色：注册A、注册B、总经理（决策项）、技术人员（维护模板）由系统管理员在“认证线成员”中指定；系统角色“销售”只能提合规报告、UPC 和表单请求并查看已发出的结果HPR-48、PR-49
URS-C-03认证线的所有写操作在同一事务内写审计（谁、何时、改了什么）H全部
URS-C-04每个认证事项只设 1 名主责，另一名注册人员复核；主责与复核不能是同一人HPR-51
URS-C-05日期按北京时间（UTC+8）计算和显示M全部

二、主表与台账

编号需求风险对应 PR
URS-C-10产品合规主表：产品、型号（UDI-DI、UPC、包装层级）、型号 × 市场的授权状态（未申请、申请中、可售、已列名、停用）；同一型号同一市场只有一条记录HPR-49
URS-C-11研发项目可以关联型号；研发项目详情页显示关联的认证项目，认证项目页可以跳到研发项目LPR-49
URS-C-12证照台账：类型、编号、持证主体、关联型号与市场、生效与到期日、费用、负责人、来源；证书扫描件存文件存储；证照与型号授权可双向查询HPR-50
URS-C-13认证项目进度：市场、路径、型号、可选关联研发项目、主责、复核、目标日期、状态；节点（测试、样品、付款、报告草稿、终稿、提交、受理、发补、回复、批准、续费等）必须有责任人和计划日期HPR-51
URS-C-14台账导入：从现有 Excel 导入项目、证照、产品台账；去重、冲突报告；每行都有负责人、日期和来源；导入后原台账只读归档HPR-54

三、提醒与看板

编号需求风险对应 PR
URS-C-20证照到期前 90、60、30 天和当天提醒；节点、派工、整改截止日前 7 天、1 天提醒；逾期当天提醒HPR-52
URS-C-21改动日期或负责人后，提醒立即按新日期重算；每晚全量重算一次兜底HPR-52
URS-C-22提醒进入负责人的工作台待办并计入角标；负责人确认后记录确认人和时间；提醒本身写审计HPR-52
URS-C-23worker 停机期间到点的提醒，恢复后补发；超过 2 小时未扫描触发告警HPR-48、PR-52
URS-C-24认证看板：未来两周节点、逾期、未来 90 天到期证照；按主责筛选；显示最近一次扫描时间MPR-53

四、申报

编号需求风险对应 PR
URS-C-30申报清单按路径生成（510(k) 按 eSTAR 章节、MDL、MDSAP）；每项可关联平台文档或上传文件，指定负责人和截止日；列出缺件HPR-56
URS-C-31一致性检查：从申报文件中抽取型号、预期用途、关键参数、材料、标签等字段，由程序比对出差异；AI 只做抽取，抽取值必须逐字出现在原文；差异由注册A 逐条确认HPR-57
URS-C-32申报状态：提交、受理、审评状态和下一动作MPR-58
URS-C-33申报快照：提交时把所交文件的版本和 sha256 清单固定下来，清单本身再算哈希存入文件存储；快照生成后不能修改或删除HPR-58

五、报告、表单、机构与测试

编号需求风险对应 PR
URS-C-40合规报告与 UPC：销售提请求 → 平台按公司模板生成底稿 → 注册B 审核 → 注册A 交叉检查 → 发出；事实句（型号、编号、日期、标准号）来自主表字段，AI 只写描述性段落HPR-59
URS-C-41美加表单预填：企业注册与列名、GUDID、MDL、MDEL 的申请与变更表单按主表预填；与主表和证照不一致的项全部列出；提交仍由注册B 在官方系统完成HPR-60
URS-C-42机构库与询价比选：机构能力、资质、联系人、历史表现；按测试项比较至少 3 家报价和周期；超出权限的费用生成管理层决策项MPR-61
URS-C-43测试进度：测试项挂认证项目；样品、合同、付款、草稿、终稿节点进入提醒；结项时回写机构表现MPR-62

六、法规监测与同类产品

编号需求风险对应 PR
URS-C-50法规监测：按官方源清单（FDA 指南与 eSTAR 版本、联邦公报、FDA 认可标准、加拿大卫生部通知）每天抓取、去重；AI 生成摘要和影响产品候选，链接必须在源清单内；注册A 确认结论；每周摘要页MPR-63
URS-C-51每个外部源可单独关闭；连续 3 次抓取失败触发告警MPR-48、PR-63
URS-C-52同类产品检索：按产品代码和关键词查询 openFDA 产品分类和 510(k)；生成同类清单与分类、路径初判候选，每条都能回到官方记录；结论只由注册A 确定HPR-64

七、发补、变更、迎审与盘点

编号需求风险对应 PR
URS-C-60发补台账：登记来函、截止日；AI 把缺陷信拆为问题项候选（每项引用原文），由注册A 确认；问题项有责任人、截止日和状态HPR-66
URS-C-61应答底稿：按问题用混合检索找历史应答和证据，生成底稿，引用必须回到原文；注册A 起草、注册B 交叉检查HPR-67
URS-C-62变更影响：设计变更增加材料、供应商、标签、型号变更类型；按主表列出受影响的型号、市场、证照和列名，生成同步待办HPR-68
URS-C-63迎审台账：按 MDSAP、ISO 13485 审核清单汇总文件、记录、证书和整改状态；整改截止日接提醒MPR-69
URS-C-64资料月度盘点：每月按清单检查缺项和版本；认证项目结项时归档路径、周期、费用、发补和经验，并入检索MPR-70

八、检索

编号需求风险对应 PR
URS-C-70混合检索：字词匹配（pg_trgm，适合编号、型号、标准号）与语义检索（pgvector）两路召回，按排名融合；中英文混合可用MPR-55
URS-C-71向量模型自部署（bge-m3），运行时不联网；记录模型名和版本，换模型可后台重算MPR-48、PR-55
