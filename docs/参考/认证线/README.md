## 范围提要

- **云端先行：** 全部功能先在云端测试环境 `idp-test.civasc.ai` 用示例认证数据和真实公开数据开发、验收；2027-02-22 随 MVP 部署到本地，导入真实台账，试点 12 周。
- **数据边界（D4）：** 云端只放示例认证数据和公开数据；真实台账、证书、发补信只在本地。
- **AI 边界：** 只做监测、整理、检查、底稿和提醒；不自动提交、不签字、不决定法规立场。所有 AI 输出都是“建议”，由注册人员采纳、修改或驳回。
- **唯一入口：** 三张主表上线并导入后，原 Excel 台账只读归档。
