二、导入模板

平台提供三份导入模板（导入页可下载，CSV 格式，用 WPS / Excel 打开填写后可直接上传 CSV，也可另存为 .xlsx 上传），第一行为列名，列名必须与模板一致；多余的列忽略并在报告中列出。

导入顺序： 先产品与型号，再证照，最后认证项目与节点。型号的“可售 / 已列名”必须关联证照，所以产品模板中的市场状态只接受“未申请、申请中、停用”；“可售 / 已列名”在证照模板的“授权状态”列设置（同时填写型号和市场）。

模板列
产品与型号产品代码、产品名称、型号、UDI-DI、UPC、包装层级、关联研发项目、美国状态、加拿大状态、来源
证照类型、编号、持证主体、型号、市场、授权状态（可售 / 已列名，可选）、生效日、到期日、费用、币种、负责人账号、来源
认证项目与节点项目名称、市场、路径、型号、关联研发项目、主责账号、复核账号、目标日期、状态、节点类型、节点内容、计划日期、完成日期、责任人账号

三、清洗规则

  1. 日期： 接受 2027-03-15、2027/3/15、2027.3.15、Excel 日期单元格与日期序列号；其他写法（例如“3 月中”）报错，不猜。UPC 被 Excel 存成数字丢掉开头的 0 时（11 位）自动补回。
  2. 人员： 按账号或显示名匹配平台账号；匹配不到时整行报错。
  3. 去重键： 产品按产品代码；型号按型号；证照按“类型 + 编号”；认证项目按“名称 + 市场”；节点按“项目 + 类型 + 内容 + 计划日期”。
  4. 已存在时： 字段完全相同则跳过；有不同则列入冲突报告（列出平台现有值与文件值），默认保留平台现有值，由注册人员在预览中逐条勾选“用导入文件覆盖”。
  5. 必填缺失： 整行报错，不导入；报告列出行号和缺的字段。
  6. 来源： 每行自动记录“文件名 第 n 行”。
  7. 先预览、后导入： 先上传得到预览报告（新增、跳过、冲突、错误），确认后才写入；写入在一个事务内完成并写审计。
  8. 原台账归档： 上传的原文件保存在平台文件存储（带版本、不可修改），导入记录页列出每次导入的原文件与结果，此后台账只在平台维护。
