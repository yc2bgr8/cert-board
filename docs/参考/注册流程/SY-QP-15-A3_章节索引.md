# 设计和开发控制程序 SY-QP-15 A3

来源是开发机上的 `SY-QP-15设计和开发控制程序.docx`。已核对文件首页的 A3 版本和 2026 年 3 月 30 日生效日期。原件及已填示例留在开发机的 `MDC/SY-QP-15设计和开发控制程序` 目录。本目录同步 22 份空白记录模板。两份通知单含样例或为避免带入其他产品示例，继续从本机原始目录查阅。

| 阶段 | 程序位置 | 记录与核对重点 |
|---|---|---|
| 策划 | 5.1，尤其 5.1.3、5.1.5、5.1.6 | 计划、风险分析、评审，以及策划阶段文件编号 |
| 输入 | 5.2，尤其 5.2.2、5.2.3、5.2.5 | 外来法规标准、风险管理计划、输入评审及编号 |
| 输出 | 5.3，尤其 5.3.2、5.3.4 | 输出清单的文件名、编号、版本和评审记录 |
| 样品试制 | 5.4，尤其 5.4.2 至 5.4.4 | 试制检验、评审和试制阶段编号 |
| 验证 | 5.5，尤其 5.5.1 和 5.5.4 | 用验证计划、验证记录和评审核对输入是否有对应证据 |
| 确认 | 5.6 | 确认报告核对用途和接受准则，结合确认评审记录使用 |
| 转换 | 5.7，尤其 5.7.3、5.7.5、5.7.6 | 试产评审、转换清单、DMR 与文件编号 |
| 设计及工程变更 | 5.8、5.9 | 核对受影响文件、版本和 DHF。注册影响另外交由审核人员判断 |

DHF 用于查项目和阶段资料，DMR 用于核对已转换的生产文件。研发、生产、采购、销售和品质的职责见第 4 章。缺件与部门归属按程序和项目证据逐项确认。样本归属不明时标为待确认。

申报和年度注册继续按需求、`docs/参考/认证线/` 及官方公开规则判断。核对对比器械时按 FDA 内容指引识别字段，再从项目的实际文件逐字取证。[FDA 510(k) 内容](https://www.fda.gov/medical-devices/premarket-notification-510k/content-510k) · [FDA 注册及列名](https://www.fda.gov/medical-devices/device-registration-and-listing/how-register-and-list)
