# M02 公开资料核查用例

E12 核对美国企业注册与列名。`l08-public.ts` 保存公开查询条件、2026-11-02 的历史观察及预期的人工确认项。E13 用同一 K 号、产品代码和四个已知商品名查询公开 UDI。申请人按法定全名独立查询企业登记。历史观察用于对照。实时回执以自己的查询时间、范围和档案为准。来源为需求 V0.4 第 11.3 节与 E12、E13。[需求 V0.4](../../docs/参考/需求文档_V0.4/AI原生器械认证与设计开发协同_需求文档_V0.4.md) · [FDA 注册与列名字段](https://open.fda.gov/fields/devicereglist_reference.pdf) · [FDA UDI 字段](https://open.fda.gov/fields/deviceudi_reference.pdf)

评测包含有记录、查询成功但零条和来源失败。成功零条的结论只覆盖当次条件。列名机构、注册号、到期年份、美国代理人企业、四个商品名、申请人登记和 UDI 查询各有待核实项。现场遇到变化需给出新回执及原因。站内提醒由程序计算日期，无任何真实联络。
