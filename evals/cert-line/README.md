# 组长认证线评测

保留参考资料快照 `sources/cert-line-assets/eval/` 中的 120 个示例和原判分口径。六类触点各 20 例，覆盖申报字段抽取、发补拆项、应答底稿、法规更新摘要、同类产品与路径初判、合规报告描述段。校验所需的纯函数来自组长项目对应认证线实现，只用于评测。

`pnpm eval` 执行同一 Pi 内核的既有剧本、R09 回归以及这组评测的原剧本。评测环境不读取模型密钥。这里的输出由原示例的剧本产生，分数衡量用例、校验和判分能否一起执行。真实模型的对照成绩见 [参考基线](../baselines/README.md)。

取得认证线完整运行报告后，可以离线生成脱敏对照。报告使用参考运行器的 `date`、`model`、`mock` 和逐例 `results` 字段。命令检查 120 个编号、触点及达标状态，输出分组差值、这次未达标的用例，以及有回执费用和缺费用的笔数。模型正文和原始错误留在输入报告中。

```sh
pnpm eval:cert-line:compare <运行报告.json> [逐例基线.json]
```

只提供运行报告时按 Flash 汇总分数比较。提供逐例基线时，命令列出两个文件记录的状态变化。逐例结论须确认两个文件使用同一判分版本。[参考基线](../baselines/README.md)
