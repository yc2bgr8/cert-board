# 组长认证线评测

保留参考资料快照 `sources/cert-line-assets/eval/` 中的 120 个示例和原判分口径。六类触点各 20 例，覆盖申报字段抽取、发补拆项、应答底稿、法规更新摘要、同类产品与路径初判、合规报告描述段。校验所需的纯函数来自组长项目对应认证线实现，只用于评测。

`pnpm eval` 执行同一 Pi 内核的既有剧本、R09 回归以及这组评测的原剧本。评测环境不读取模型密钥。这里的输出由原示例的剧本产生，分数衡量用例、校验和判分能否一起执行。真实模型的对照成绩见 [参考基线](../baselines/README.md)。

真实认证线评测在 PR-36 的独立 Linux 验收运行中执行。初始化本机验收库后，验收入口加入 `--acceptance eval:cert-line:real`。模型使用现有获准的开发评测配置，沿用模型网关、代理、零保留及计量。派发前核对验收进程仍在运行。每例各有独立运行和账本关联，汇总保存在验收报告同目录的 `cert-line-result.json`。

六份 `prompts/*.v0.1.md` 从参考资料快照的 `sources/cert-line-assets/prompts/` 逐字复制。运行时核对文件摘要，按原变量、0.2 温度、4,000 输出上限与原判分逐例执行。批次按顺序运行，已有计量的 JSON 格式问题最多发起三次，其余派发错误中止批次。中止时保留已完成用例及待核对请求编号，报告不会被当作完整成绩。逐例报告只包含状态、固定失败类别、已知用量与费用。

取得认证线完整运行报告后，可以离线生成脱敏对照。报告使用参考运行器的 `date`、`model`、`mock` 和逐例 `results` 字段。命令检查 120 个编号、触点及达标状态，输出分组差值、这次未达标的用例，以及有回执费用和缺费用的笔数。

```sh
pnpm eval:cert-line:compare <运行报告.json> [逐例基线.json]
```

只提供运行报告时按 Flash 汇总分数比较。提供逐例基线时，命令列出两个文件记录的状态变化。对照摘要会标出提示词摘要相同、有变化或无法核对。逐例结论还须确认两个文件使用同一判分版本。[参考基线](../baselines/README.md)
